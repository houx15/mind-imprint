# PBL 网页制作交互设计工作区

本目录用于 Lite 版本 PBL 项目中“制作网页”的交互设计原型。以下约束适用于本目录及其所有子目录，必须持续遵守。

## 工作范围

- 所有新增、修改和删除都必须限定在 `apps/lite-web/src/eco/` 内。
- 可以只读查看仓库其他目录和线上对应功能，用于理解现状、接口和视觉语言；不得修改本目录之外的文件。
- 本目录只承担交互设计和可演示原型，不直接改造正式 Lite 功能代码。
- 若任务确实需要修改本目录之外的代码，必须先停止并取得用户明确授权。

## 分支与协作

- 只在分支 `codex/pbl-web-layout` 上开展本项工作。
- 开始工作前检查当前分支和工作区状态；若不在该分支，不得继续修改。
- 不直接向 `main` 提交或推送。
- 完成并验证设计后，通过该分支提交 Pull Request，请仓库维护者 `houx15` 审核和合并。
- 未经用户明确要求，不执行合并、部署或发布。

## 项目依据

- 每次开始相关开发前，先阅读 `apps/lite-web/README.md`。
- 同时遵守仓库根目录 `AGENTS.md` 的产品原则、界面文案规范、安全约束和测试要求。
- 若本文件与上层规则冲突，采用限制更严格且不扩大工作范围的规则；无法判断时先询问用户。

## 验证与交付

- 设计必须能以真实浏览器查看和操作，不能只凭类型检查或组件测试判断完成。
- 提交前确认改动范围没有越出 `apps/lite-web/src/eco/`。
- PR 描述应明确说明这是交互设计原型、验证方式、已知限制，以及没有改动正式 Lite 功能代码。
