## 修改标准

学生需要理解时，老师联系当前问题，引导观察、比较和解释。学生明确索答或询问概念时直接解释；已经完成要求时继续下一步。不能把温和语气理解成每轮先夸一句，也不能把教学理解成先公布结论再让学生复述。

界面仍负责命名和说明操作；对话使用自然、完整的句子。保留学生原话、原始试题、外部引文，以及有意展示的教学反例。没有把代码注释或历史开发文档当成学生文案清洗。

## 本轮调整

- 阅读：陪练语气、比较与求提示的示例、步骤说明、阅读总结出现时机、透镜反馈、阅读卡片及提交状态。撤掉每轮必须加粗的机械要求。
- 写作：段落构成说明、规划、引导、批注、问题名称、语气重试说明。删除“最弱”“一面之词”等诱导措辞；明确反馈不得把“一个有帮助的方案”扩大成“唯一方案”。
- 兴趣探索：功能提示、角色语气、重问与结束提示。KIRO 开场白改为邀请比较证据；新录音随应用打包，避免继续播放旧的贬低性台词。该录音使用服务端已配置的 TTS 音色，不保证与旧 CDN 录音音色完全相同。
- 项目与教师页面：操作、缺项、错误、报告和教师提示；课程营销页的标题及中英文介绍改为具体学习活动。
- 共用教学表达：阅读计划、写作规划与引导、批注、教师批改、兴趣对话共用文字表达规则，涵盖所有可见字段；不做输出字符串替换，不改引用内容或模型路由。教师批改明确按实际文体评价，不能因议论文没有人物对话或动作描写而扣分。
- 共用方法词表：前后端副本同步修改定义，保留标识符、正式名称和原有教学例子。

其余更新的生产提示词已按变更范围检查：项目陪练、来源分析、成果生成、过程报告、兴趣提取、教师端生成及题库。对没有发现本轮表达问题的部分保留原文；没有为获得统一语气而改写所有提示词。

`changed-files.tsv` 是 apps/packages 变更路径的分类清单，包含用于确定范围的测试和资源文件，不表示每项都是面向学生的文案。线上数据库课程正文和旧会话记录不在本地源码审阅范围内，旧生成内容不会被本轮自动重写。

## 失败记录与判据修正

`baseline` 在第一批共享写作说明已修改后采集，并非未经修改的 main；各轮检查逐步加严，不能直接拿失败率作严格前后对照。

所有试验批次均保留，文件名中的 `final`、`verify` 是当时的试验名称，不代表该批次全部通过。

- 早期批次出现内部段落 ID、过早给答案、重复追问、把部分作答判为完成，以及继续使用“站得住”等情况。逐项用于修改提示词，没有删除失败样本。
- 兴趣探索结束时仍问“这样理解对吗”：移除了与“结束不再提问”冲突的通用示例，再复测三位助手。
- 原始批注有时把逐字引文写在 text 而非 quote。生产已有引用恢复逻辑，因此验收改为检查恢复后交付的引文，不能将“缺字段”和“编造引文”混为一谈。
- 写作首次输出仍会触发已有总评或结构校验；保留首次失败记录，另测真实的重试流程，不把重试成功写成首次成功。
- 一个完整作答样本把当前步骤定位在第三段，学生却引用第二段数字。修正为第三段的完整回答；比较任务也定位到学生实际引用的第二段。旧样本保留，不将这个定位冲突归咎于模型。
- 原来的连续对话测试只查步骤。本轮增加首次提示不能直接摘出完整答案原句的判据，并人工阅读完整对话；状态正确并不等于教学质量合格。曾尝试把提示里出现数字一律判错，但学生问的是怎样解释“这个数字”，仅指出数字、继续请她解释可以是有效线索；所以保留完整答案泄漏检查，不把所有数字都当成错误。

- 扩大检查到引导框、摘要及批改字段后，发现之前仅查解析的样本仍出现“主张”“撑”等。添加共享表达规则，并删除阅读计划里仍含“补贴能撑多久”的正面示例。
- 阅读计划的机器定位字段本来就包含 b1 等编号。检查修正为仅检查真正展示的文本字段，保留对可见文本泄露编号的检查。
- 写作规划测试原来未展开文体节点模板，本轮改用生产 `writingPlanSystemFor`；保留学生说“我想主张延长开放”的输入，确认老师自己的转述会使用清楚的表达。
- 批注总评的生产校验采用保守子串匹配，“学生缺少安静场所”也会触发“缺”。本轮未放松校验，改为在总评概述主题和表达方式，把具体问题与原文放入批注。
- 教师批改发现少于三条意见和不完整 JSON；保留原有 3–5 条契约及有限重试，提示明确可给两条优点与一条问题，不为满足数量虚构缺点。
- 阅读输出改为先写 advance、再写 reply，防止把老师本轮补充的解释当作学生已答。字段名与含义保持不变，仍由原解析器读取。
- 人工阅读发现部分作答的回复虽未推进，却先说出完整统计对象。本轮进一步区分“提示缺少的信息类型”和“替学生说出答案”，新增对应检查。词表检查不是完整的教学质量判官，仍须查看全部回复。

真实调用需要有当前服务端模型通道的凭据文件，使用新的输出目录，以免覆盖旧样本：

```sh
CLARITY_LIVE=1 CLARITY_ENV_FILE=/path/to/server.env \
CLARITY_OUT=/tmp/copy-review-new-run CLARITY_SAMPLES=2 \
go test ./internal/api ./internal/awakening -run TestClarity -v -count=1 -timeout 20m
```
