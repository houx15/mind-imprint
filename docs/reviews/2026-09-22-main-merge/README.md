## 证据解释与限制

`final-samples.json` 由最终完整批次组合：`semantic` 除之后再次改过的写作邀请；`reading-final` 除之后再次改过的透镜；`retries` 的全部记录。每个调用点使用其最后一轮完整样本，不从同轮中挑成功输出。原始失败批次保留，文件名含 final/accept 不意味着该历史批次全通过。`requests.json.gz` 保存请求、输出、实际模型、缓存与用量；未保存密钥或模型推理。

这些检查证明有限样本中的格式、节点分类、推进与指定表达规则，不保证所有未来输出的教学质量。人工审读仍可看到少量生硬表达、句子较长、解释关系不够精确，以及偶尔产生随后被生产逻辑过滤的空节点。英文回复仍有中英文混用不够自然的情况。没有把自动检查通过等同于彻底消除 AI 味，也没有改写线上已有历史对话或课程原文。
