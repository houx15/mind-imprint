# 个人主页与项目教练迭代

日期：2026-09-22。基线：origin/main `b89fd0e6`。开发分支：`codex/pbl-homepage-coach`。

## 本轮产品边界

个人主页是学生介绍自己、选择并分享平台成果的独立页面，不需要先完成 persona 或主页项目。提供三种有结构区别的版式、六套配色、字体选择、写作与阅读的展示方式、内容选择与排序。预览与访客页面复用同一渲染器。保存草稿与发布分开，旧站点与旧项目历史保留，明确发布新版后才替换公开展示。

项目是 AI 项目教练：通过对话讨论目标与计划，用计划表呈现步骤、学生和 AI 的分工、预期交付物；学生可提交每一步的成果和说明。学生可以在外部 coding agent 或其他工具里制作，不要求导入完整对话、安装 skill 或往返同步。已有 persona、board 等思考工具按需要使用。

后续互动课程会讲解 agent、skill、coding 和 AI 协作。课程尚未开发，本轮不创建假课程或将课程作为项目推进门槛。现有真实课程功能保留。

## 实施顺序

1. 独立主页数据与发布快照，验证归属、选择范围、撤销和并发冲突。
2. 主页编辑器及共用展示组件，验证多种版式、配色和移动端预览。
3. 解除主页发布对项目创建的限制，补齐逐步骤交付物提交与回灌。
4. 调整项目教练提示词，验证计划、学生与 AI 分工、外部制作场景。

每个独立完成并验证的部分单独 commit；不将全部工作累积到最后。不推送、不部署。

## 验收

- 新学生不需要主页项目即可编辑主页、保存、重载；未发布草稿不会改变公开页面。
- 版式、色调、字体和展示方式选择在预览与公开页面一致，窄屏可用。
- 只有学生主动选择的成果出现在主页；阅读/写作仅从已公开作品中选择，撤销后不再展示。
- 旧主页默认保持原状，切换新版是明确发布操作。
- 无主页的学生可以创建项目；计划保留学生与 AI 分工，每步支持交付物记录。
- 真实模型验证与离线逻辑测试分开报告；未测试的行为明确列出。
