## 这是什么

这是平台的**交互式工具包总目录**。每个工具包是一个 `.md` 文件，描述一种"思维脚手架"：在学生与 AI 对话、做作业、看材料的过程中，系统识别到合适的情境就**自动浮现**（或学生主动点开）一张工具卡，把 AI 从"给答案的助手"切换成"陪我思考的脚手架"。

每个文件回答四件事（产品概念里学生侧最关心的）：

1. **是什么** —— 工具本身的解释与原理出处。
2. **什么时候被触发** —— 触发情境 + 可被 AI 识别的信号 / 关键词。
3. **用来做什么** —— 目标与学生收获。
4. **应该如何交互** —— 学生看到什么、AI 怎么动、分步脚本、就地小讲解。

并额外给出开发所需的：**渲染字段**、**AI 克制红线**、**过程留痕数据**、**对应 rubric 维度**。

核心原则（贯穿全库）：**奖励"思考本身"，AI 绝不替学生定论；触发本身就是一次互动，跳过/绕过也是被记录的数据。**

## 渐进式披露（Progressive Disclosure）

工具包很多（30+），不能一次全堆给学生或 AI。采用**两层渐进披露**：

### A. 系统层：按"披露层级"决定何时让某个工具包进入视野

| 层级 | 名称 | 何时出现 | 数量 | 设计意图 |
| --- | --- | --- | --- | --- |
| `tier-0` | 常驻核心 | 任何对话默认可用（界面右侧常驻 3-5 张） | 少 | 高频、跨学科、零门槛 |
| `tier-1` | 情境浮现 | AI 识别到触发信号时，浮一张"建议卡"，学生确认才展开 | 中 | 不打断、按需出现 |
| `tier-2` | 深入 / 学科 / 教师启用 | 进入特定学科任务、学生已走到更深环节、或教师在课程里预置 | 多 | 避免低龄/新手过载 |

**路由逻辑（给 AI / 后端）**：每轮学生发言 → 匹配各工具包 frontmatter 的 `trigger_keywords` 与 `trigger_context` → 命中则按 `disclosure_tier` 决定是"直接切换模式"(tier-0) 还是"浮现建议卡"(tier-1/2) → 学生接受 / 跳过 / 让 AI 直接给答案，三种动作**全部记录**。同一情境命中多张卡时，按 `priority`(P0>P1>P2) 取一张主推，其余折叠进"还可以试试"。

### B. 卡内层：每张卡内部的"就地小讲解"也分层

学生默认只看到**最简操作界面**（一句引导 + 输入位）。若有疑问，点"这是什么？/ 为什么这么做？/ 看个例子"——再就地展开讲解、原理、范例。**先用，再懂；不强迫学习框架本身。**

## 每个工具包的 frontmatter 规范

每个 `.md` 顶部用 YAML frontmatter，供后端路由与前端渲染解析：

```yaml
---
id: sift                      # 唯一英文 id（kebab-case）
name_zh: 横向核查卡            # 中文名
name_en: SIFT Lateral Reading # 英文名
category: 信息素养            # 八大类之一
priority: P0                  # P0 / P1 / P2
disclosure_tier: tier-0      # tier-0 常驻 / tier-1 情境浮现 / tier-2 深入
age_band: [MYP, DP]          # 适用学段 PYP/MYP/DP（或 初中+/高中）
trigger_keywords: [来源, 可信吗, 这是真的吗, 谁说的]   # 学生话里可命中的词
trigger_context: 学生准备引用某来源 / 直接相信 AI 给的事实   # 情境描述（供 AI 语义匹配）
interaction_type: 步骤引导卡   # 卡片形态（见下）
rubric_dims: [D2, D3]        # 对应评估维度（D1-D9 / OPCVL D1-D12）
related: [craap, money-trail] # 关联工具包 id
---
```

`interaction_type` 取值约定：`步骤引导卡`（多步流程）/ `选择追问卡`（选项触发追问）/ `分类标注卡`（拖拽/打标）/ `量表光谱卡`（滑块定位）/ `角色模拟卡`（扮演对话）/ `画布导图卡`（节点连线）/ `回放验证卡`（无 AI 复述）/ `报告生成卡`（结构化产出）。

## 每个工具包的正文结构（统一模板）

1. **一句话定位**
2. **工具包解释**（是什么 + 原理/出处）
3. **何时被触发**（触发情境、可识别信号、谁可触发）
4. **用来做什么**（目标 + 学生收获）
5. **如何交互**（界面元素 → 分步脚本 → 就地小讲解的渐进披露）
6. **AI 克制红线**（可以做 / 绝不能做）
7. **过程留痕**（记录什么 → 对应 rubric 维度）
8. **渲染要点**（卡片字段，给开发）
9. **示例片段**（一段对话示例）
