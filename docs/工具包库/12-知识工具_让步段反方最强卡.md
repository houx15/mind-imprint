# 让步段·反方最强卡（Steelman）· Strongest Counterargument

## 一句话定位
不打稻草人——先把反方**最强**的版本说出来，再回应它。这是让论证从"片面"变"可信"的关键一步。

## 工具包解释
Steelman（与 strawman 相对）：主动构建对立方最有力的论证，再据此回应。配合议论文的"让步段"（concession + rebuttal）。它直接对应评估维度 D4"多视角与让步"，是高分议论文与普通议论文的分水岭之一。点这张卡时，AI 从"顺着你"切换为"给你最强反方"。

## 何时被触发
- **情境**：学生只写自己一方；或想检验自己立场是否经得起反驳。
- **可识别信号**：通篇单向论证、无反方；学生说"我觉得我说得挺全"；写作进入论证中段。
- **谁可触发**：系统浮现；学生主动点；议论文/与AI协作课。

## 用来做什么
- 目标：生成反方最强论证并让学生回应。
- 学生收获：论证更结实；体会"认真对待对手"反而让自己更有力。

## 如何交互
**界面元素**：你的立场条 + "反方最强"生成区 + 让步段模板（我承认…但…因为…）。

**分步脚本**
1. 确认学生立场。
2. AI **给出反方最强论证**（不是弱化版），并问"如果你是对方，最有力的一击是什么？"先让学生自己试。
3. 学生写让步段："我承认【反方有理之处】，但【我的回应】，因为【理由/证据】。"
4. AI 检查：让步是否真诚（没有偷偷弱化反方）、回应是否扣住反方最强点。

**就地小讲解**："为什么要帮对方说话？"→ "因为驳倒一个弱版本不算赢。能回应最强版本，你的立场才真的立得住。"

## AI 克制红线
- 可以：给出反方最强论证、检查让步是否真诚、追问。
- 绝不能：替学生写回应、把反方故意弱化以讨好学生、替学生定胜负。

## 过程留痕
- 记录：是否生成并直面反方最强、让步真诚度、回应是否扣题。
- 对应维度：D4 多视角与让步。

## 渲染要点
```json
{ "type":"steelman", "your_stance":"",
  "counter_strongest":"", "concession_template":"我承认___，但___，因为___。",
  "checks":["让步是否真诚","是否回应了最强点"] }
```

## 示例片段
> 学生：我认为学校该禁手机，理由很充分了。
> 卡片：先听反方最强的一击——"手机是安全与联络工具，一刀切禁会让家长无法在紧急时联系孩子"。你会怎么让步并回应？
> 学生：我承认紧急联络很重要…
> AI：好开头。你的"但是"要怎么既保留这个顾虑、又支持你的立场？
