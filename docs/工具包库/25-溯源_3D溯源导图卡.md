# 3D 溯源导图卡 · 3D Source-Tracing Map

## 一句话定位
把一串聊天记录和零散材料，转成一张立体的导图：概念、来源、观点、利益相关方、偏见、兴趣点各成节点，看清谁支持谁、谁出钱、谁有偏见。

## 工具包解释
源自人工辅导阶段的打标方法：把学生的资料、问题、观点、偏见、证据、兴趣点全部标出来，最终产出一张全面立体的导图。节点类型：概念、资料来源、观点、利益相关方、偏见、学生兴趣。每个节点点开是细节化、经专业评估的材料，并标注它可能携带的偏见。核心不是制造"无偏见世界"，而是让学生看见"所有材料都有立场，关键是意识到并在偏见中建立更负责任的判断"。

## 何时被触发
- **情境**：议题材料积累到一定量；探究中期需要全局梳理。
- **可识别信号**：`trigger_keywords`；多来源多观点并存；学生说"有点乱"。
- **谁可触发**：系统在材料积累后建议生成；学生主动点；探究项目中段。

## 用来做什么
- 目标：把探究过程可视化为可追溯的关系网。
- 学生收获：看见自己的探究全貌；理解立场与偏见的结构。

## 如何交互
**界面元素**：节点画布（六类节点 + 连线：支持/反对/出资/源自）+ 节点详情抽屉（材料+偏见标注）+ 偏见图层开关。

**分步脚本**
1. 系统把对话中的材料/观点自动抽成候选节点，学生确认入图。
2. 学生连线标关系（这条支持那个观点 / 这家出钱给那份报告）。
3. 给来源节点标偏见（政治/商业/地域/叙事）。
4. 打开"偏见图层"看全局：哪些观点其实同源、谁在背后。
5. 收口："看完这张图，你的判断有变化吗？"

**就地小讲解**："标了偏见，是不是就不能用了？"→ "不是。所有材料都有立场。看见它，你才能在偏见中做更负责任的判断。"

## AI 克制红线
- 可以：抽取候选节点、提示可能的关系与偏见、追问。
- 绝不能：替学生连定关系、替学生给"这就是真相"的全局结论。

## 过程留痕
- 记录：节点与连线数量、是否标注偏见、是否发现同源、判断是否随之修正。
- 对应维度：D3、D4、D5。
