# 信源辨识卡 CRAAP / CRRAAB · Source Evaluation

## 一句话定位
对**单一来源**做纵向体检：从时效、相关、权威、准确、目的（+ 偏见）几个维度，把"能不能引用"变成一组可判断的问题，而不是 AI 替你拍板。

## 工具包解释
CRAAP / CRRAAB 是图书馆信息素养经典框架：Currency 时效、Relevance 相关、Authority 权威、Accuracy 准确、Purpose 目的（CRRAAB 另含 Reliability 可靠与 Bias 偏见）。本卡也吸收了《纵深路线》中"信息评估卡"的五维（时效/相关/权威/准确/偏见）。核心不是机械填表，而是养成**判断信息的习惯**。它常和 SIFT（横向核查）配对：CRAAP 看"这个来源本身像不像"，SIFT 看"别人怎么评价这个来源"。

## 何时被触发
- **情境**：学生准备引用、或已经相信某个具体来源。
- **可识别信号**：粘贴/提到一个 URL、媒体名、"我看到一篇…"、"数据显示…"。
- **谁可触发**：系统自动浮现；学生主动点；学术写作课中作为引用前必经。

## 用来做什么
- 目标：让学生对来源形成自己的"可信度判断 + 理由"。
- 学生收获：从"找资料"转向"判断资料"；知道一个来源可能在哪一维出问题。

## 如何交互
**界面元素**：5-6 维度行（每行一个引导问题 + 学生判断：可信/存疑/不可信 + 一句理由）+ 汇总结论条。

**分步脚本**
1. 学生贴入来源 → 卡片逐维抛"引导问题"（一次一维，不一次性铺满）：时效"什么时候发布的？数据更新了吗？"…偏见"它可能有什么立场？"
2. 每维学生给判断 + 一句理由，AI 只追问"你凭什么这么说"，不替判断。
3. 汇总："综合看，你会怎么用它——直接引用 / 交叉验证后用 / 不用？"
4. 若多维存疑 → 建议接 SIFT 卡横向核查。

**就地小讲解**：每维旁"这维在看什么？"可展开定义与一个反例。

## AI 克制红线
- 可以：给维度问题、追问理由、提示某维可能被忽略。
- 绝不能：替学生判定来源"可信/不可信"、替学生决定引不引用。

## 过程留痕
- 记录：各维判断与理由、是否补充交叉验证、最终引用决定。
- 对应维度：D2 信源辨识。

## 渲染要点
```json
{ "type":"craap", "source":{"url":"","title":""},
  "dimensions":[{"key":"currency","q":"何时发布？是否过时？"},{"key":"relevance","q":"是否直接回答你的问题？"},{"key":"authority","q":"作者/机构可信吗？"},{"key":"accuracy","q":"能否被其他来源验证？"},{"key":"purpose","q":"为何而写？"},{"key":"bias","q":"可能有什么立场？"}],
  "verdict_options":["可信","存疑","不可信"] }
```

## 示例片段
> 学生：我想引用《经济学人》这篇讲气候的。
> 卡片：先体检一下。时效——这篇是哪年的？相关——它直接回答你的问题，还是只给背景？
> 学生：2019 年，主要是背景。
> AI：那"相关"这一维你会打几分？为什么？（不说能不能引用）
