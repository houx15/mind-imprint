# 事实/观点/价值判断卡 · Fact / Opinion / Value

## 一句话定位
把一段话里的陈述分成三类——能查证的事实、需论证的观点、藏着价值的判断，是一切清晰思考的地基。

## 工具包解释
区分三类陈述并各配一个检验：**事实**=能被查证（可核查）；**观点**=需要论证（要给理由）；**价值判断**=藏着价值排序（"应该/好坏"）。锚点：气候、长滩岛大亨vs主教、哥伦布。它服务于 TOK 框架的"范围+方法"地基——先分清知识的种类，才能正确处理它。

## 何时被触发
- **情境**：学生把"我觉得/应该"当成"事实"；或一段话三类混杂需要拆。
- **可识别信号**：`trigger_keywords`；学生用"显然/大家都知道"包装观点；写作前梳理论点。
- **谁可触发**：系统自动浮现（tier-0）；多门课的前置基本功。

## 用来做什么
- 目标：给每句话正确归类并配上对应的检验。
- 学生收获：不再用"事实"的口气说观点；知道每类该怎么对待。

## 如何交互
**界面元素**：句子拆条 + 三色标签（事实/观点/价值）+ 每类对应检验提示。

**分步脚本**
1. 学生贴入一段话 → 系统切成单句。
2. 学生给每句贴标签，AI 追问"它能被查证吗？需要理由吗？藏了'应该'吗？"
3. 对"事实"句 → 提示去核查；对"观点"句 → 提示补论证（接论证地图）；对"价值"句 → 提示说明价值前提。
4. 汇总：这段里真正的事实有几条，其余需要怎么处理。

**就地小讲解**："观点和价值判断有什么区别？"→ "观点是'我认为 X 是真的'（可论证）；价值判断是'X 是好的/应该的'（背后有价值排序）。"

## AI 克制红线
- 可以：切句、给检验问题、追问归类理由。
- 绝不能：替学生贴标签、替学生判定某观点对错。

## 过程留痕
- 记录：归类准确度、是否为观点补论证、是否识别隐藏价值。
- 对应维度：D4、D5。

## 示例片段
> 学生：哥伦布是个英雄，他发现了新大陆，改变了世界。
> 卡片：拆三句。"他到达了美洲"——哪类？
> 学生：事实。
> AI：对，可查证。那"他是个英雄"是哪类？它能被查证，还是藏了一个价值判断？
