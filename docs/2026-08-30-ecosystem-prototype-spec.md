# 生态原型 · 世界 / 我的树 / PBL — Static Frontend Prototype Spec

> 2026-08-30 · lite edition (`apps/lite-web/src/eco/`), mounted at `/eco/*`.
> **Pure frontend.** No API, no persistence beyond `sessionStorage`. Every
> screen walks end-to-end on mock data so the flow can be judged before any
> backend is written.

## 关键词
易用 · 清晰 · 有趣 · 科技感。四个词都要能在每一屏上指出来。

## 0 · 一句话
把「思维印记」从两个房间（阅读 / 写作）扩成一个**生态**：
**世界**给她值得好奇的东西，**我的树**把她的好奇长成她自己的样子，
**项目 (PBL)** 让她把它做出来，**我的主页**是这一切的家。

## 1 · 双视图首页 · 世界 ⇄ 我的家

一个开关，两个世界。切换本身是产品的第一个「哇」。

| | 世界 | 我的家 |
|---|---|---|
| 底色 | 暖夜空（近黑暖调 + 星尘） | 暖纸（`--mk-paper`） |
| 隐喻 | 向外 · 未被发现的行星 | 向内 · 正在长的树 |
| 时间 | 换一天 → 换一批新闻 | 拖时间 → 看树怎么长起来的 |

两边都有时间轴，方向相反 —— 这是刻意的对称：**世界随时间流动，我随时间生长。**

## 2 · 世界 · 新闻星图

- **每天正好五颗**。不是信息流，是五件值得知道的事。
- **行星漂浮**：不同轨道半径、大小（大小=重要度）、颜色（=领域）。慢速漂移 + 指针视差。
- **等待被发现**：未点开的行星蒙着一层，只有一个领域符号。点亮后才显示标题。计数写作「你点亮了 2 / 5」——只在当天，**没有连胜、没有排行榜、没有徽章**（铁律②）。
- **钩子问题**：每颗行星有一个问题，不是摘要。悬停时它先出现，标题在后。
- **中 / EN**：标题、摘要、钩子问题都是双语，一键切换。
- **不谈政治**：政治与冲突类**在源头过滤**，并且**明说**——一枚可点开的说明片「已过滤：政治与冲突」，解释我们为什么不在这里讨论它。
- **领域筛选**：科技 / 科学 / 环境 / 太空 / 健康 / 文化 / 经济 / 教育。
- **打开一颗** → 侧面板：钩子问题（最大）、双语摘要、来源与日期、四个出口：
  `读这篇` → 阅读室 ｜ `问印记` → 对话 ｜ `收进我的树` → 长一个关键词 ｜ `做成项目` → PBL。
- **为什么是这五条**：一枚透明度说明，讲清挑选标准。

## 2.1 · 真新闻从哪来（下一步，不在本原型里）

原型里的 25 条是**手写的示例内容**，界面上有「原型数据」标识。接真数据时，
`NewsItem`（`eco/data/types.ts`）的形状不用改 —— 它就是按这条流水线的产物设计的：

```
新闻源 API ──► ① 抓取（每日一次，按领域拉 100~300 条）
              ② 政治/冲突过滤（分类器 + 关键词黑名单；宁可错杀）
              ③ 去重（同一事件多家报道，聚成一条）
              ④ 排序打分 → 取前 5（打分标准 = SELECTION_NOTE 那五条）
              ⑤ LLM 一次调用生成：双语标题/摘要 + 钩子问题 + keywords
              ⑥ 落库缓存（每天一张 5 条的表，供当天所有学生共用）
```

**几个已经能定的决定：**
- **每天一次批处理，不是按人生成。** 五条对全校是同一份，所以是 1 次/天的成本，
  不是 1 次/学生。这也让「今天大家都看过这五条」成为教室里可以讨论的事。
- **钩子问题是 LLM 写的，标题和摘要也是 LLM 译写的**，所以三者都要标注来源：
  卡片上写清楚原始出处（`source`），不冒充原文。走旗舰档模型（评估不降级同理），
  一天 5 条的量，成本可以忽略。
- **政治过滤放在第 ② 步（入库前），不是第 ⑤ 步（渲染前）。** 过滤发生在数据层，
  界面只负责把「我们过滤了什么、为什么」说出来（`POLITICS_NOTE`）。
- **候选源**（待定，需要评估版权与中国大陆可达性）：GNews / NewsAPI /
  Currents / 各机构 RSS（Nature、Science、NASA、ESA、IEA、WHO）。
  科研机构的 RSS 反而最合适 —— 天然少政治、天然有出处、天然「改变了一个事实」。

⏸ 本轮不做：原型的目的是先确认交互与信息结构。数据管线在形态定稿之后再接。

## 3 · 我的家 · 会长大的树

> **视觉定稿（2026-08-31）：抽象，不卡通。** 第一版画了一棵字面意义的树（棕色树干、
> 绿色糖果药丸），像儿童插画。现在：树是**半透明的结构图**（向梢部渐隐的渐变细线、
> 镜像根系、极淡的年轮），退到背景里；关键词是**技术标注** —— 精确落在枝上的菱形
> 标记 + 引线 + 直角标签，标签上是等宽读数（`SRC 3 · STR 4/5`）。结构后退，她的词在前。
> 年轮与「世界」的轨道环刻意呼应：向外是轨道，向内是年轮。

- **主干 = 我**；**主枝 = 领域**（人文与写作 / 科学与自然 / 社会与世界 / 技术与创造 / 艺术与表达 / 自我与成长）。
- **关键词长在枝上**：由她的阅读 / 写作 / 项目 / 活动生成。强度是**读数**（`STR 4/5`）不是等级，来源数同理（`SRC 3`）。
- **高光时刻**：标签上一枚 ✳ 与彩色读数，「那一刻你…」——她做得特别好的一次，钉在它发生的地方。
- **点开一个关键词** → 抽屉：它是什么 · 它从哪来（可点的来源清单：3 篇阅读 / 1 篇写作 / 1 个项目）· 印记看见的证据（她自己的原话）· 四个下一步（继续读 / 写一篇 / 做个项目 / 问印记）。
- **成长回放**：4 个时间点（三月 / 五月 / 七月 / 现在），枝随之伸长、词随之出现。
- **底部行动坞**：读 · 写 · 做 · 聊 —— 四个入口，一直在手边。

## 4 · 印记 · 她自己的 AI

右侧抽屉，任何页面都能叫出来。带上下文（在哪一屏、正看着什么）。
说话方式遵守 [印记 must talk like a teacher]：有利害、有真方法名、给选择、可以给例子。**一次只问一个。**

## 5 · PBL

### 5.0 第一个项目 · 建一个属于你的主页（解锁其余）
不是人为的锁。理由是真的：**之后每一个项目都会发布在这里，所以先把家建好。**

六步，可回退：
1. **看看别人的家** —— 6 个真实优秀个人主页，每个标注「它好在哪」和「你能偷走的那一招」。
2. **学会下清楚的指令** —— 本模块的教学核心。AI 在明确指令下才好用，「明确」= 三样东西：
   - **直接的例子**：你要它像哪一个；
   - **内容的结构**：哪几块、什么顺序；
   - **你想怎么和 AI 合作**：`AI 提问我来答` / `AI 提方案我来定` / `我来写 AI 只整理`。
   三样选完，屏幕**把它编译成一段真的指令**给她看：「这就是你给 AI 的指令」。
3. **选风格** —— 4 张带实时预览的风格卡。
4. **写内容** —— 分块写。**三种合作模式在这里真的不一样**（提问式 / 提案式 / 整理式）。可以从**我读过的**和**我写的**里挑，放上主页。
5. **发布** —— 预览真实页面，拿到链接。
6. **分享** —— 分享卡 + 二维码。主页从此在首页可达。

### 5.1 其他项目
- **五条赛道**：一个设计 · 一个网站 · 一个游戏 · 一份调查报告 · 其他。
- **两个入口**：直接选赛道 ｜ 先和印记聊（它从我的树 + 我收藏的新闻里提议）。
- **为什么（动机）—— 花最多时间的一步**：三层追问（为谁做？不做会怎样？你自己为什么在乎？），印记会对敷衍的回答追一次。产出一张**动机卡**，钉在项目头部，后面反复回来提醒「你当初说…」。
- **AI 排步骤**：学 / 查 / 设计 / 做 / 记录 / 试 / 发布。步骤可改可加可换序（排计划是系统的确定性动作，不需要「防操纵」确认门槛）。
- **一步一个工作台**：印记在侧，中间是这一步专属的工具（迷你课 / 问卷搭建器 + 假回收 / 灵感板 / 文档）。
- **发布** → 项目卡出现在她的个人主页上。闭环。

## 6 · 阅读 / 写作（轻量接入）
原型里是静态书架 + 静态篇目，作用是两条：**喂养树上的关键词**，以及**可被挑到主页上**。

## 7 · 科技感怎么落地（不是霓虹青色）
等宽小字号系统标签（`SIGNAL · 08-30`、`FIELD 04`）· 发丝线 · 点阵 · 轨道环 · 坐标刻度 · 数值读数（权重 0.82 / 来源 3）· 慢漂移与视差 · 逐项错峰入场。暖色底 + 马卡龙辉光，不用赛博霓虹。
