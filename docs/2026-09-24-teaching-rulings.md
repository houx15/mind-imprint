# 教学素材里那几处冲突，怎么定的（2026-09-24）

`docs/reference/writing-teaching/distilled/README.md` 最后一节列了几处「来源内部
互相矛盾，要产品负责人选边」。这份文件把它们定下来，并写清**定错了会怎样、
怎么改回去** —— 每一条都是可撤的。

产品负责人 2026-09-24 的指示是「go ahead」，所以这几条由工程先定、标出来，
不停下来等。下面每一条的「如果你不同意」那行就是撤回的入口。

---

## 1. 词数超标：扣分，不压档 —— 这一条原来不是冲突

**定：** 词数是**一处独立的扣分**（应用文 80 词左右，`<60` 或 `>100` 扣 2 分）；
**要点缺失**才影响档次上限（缺 1 个通常不高于四档，缺一半以上不高于三档）。

**为什么这不是选边：** 把两份 rubric 摊开看，它们说的根本是两件事 ——

- `[C]references/rubric.md` 与 `[G]` 两份都写着「词数 <60 或 >100 → 总分减 2 分」；
- 「档次上限受限」那句话出自**要点遗漏**那一条，和词数无关。

我原来把这两句并排读成了一处冲突。它不是。两条各自照原样实现即可。

**已落地：** `WritingPlanSkeletonLetterEN` 里写的是「明显偏少或者明显超出都要
扣分」，并据此禁掉「再补一个理由把这一段写厚」。

---

## 2. 结尾加一句谚语：按学段分，而且真正的判据是「接不接得上」

**定：**

- **初中**：结尾加一句谚语或感叹句算**升格建议**，照 `[W]` 的 rubric 给。
- **高中／高考**：不主动建议；只有当它**与上下文脱节**时才标出来，说明理由。

**为什么这是解释而不是折中：** 高考那份 rubric 的原话不是「不许用谚语」，是
「低水平习作中出现与水平不匹配的『背模板句』要标注出来，并提示『与上下文
脱节、有背诵痕迹』」。**被判的是脱节，不是谚语。** 于是两份 rubric 的真正
差别只剩「初中要不要主动推荐它」，而那正是学段的差别。

**为什么落得下去：** 学段这条轴已经有了 —— `guidance.Key.Grade` 加
`classes.grade`，junior / senior 分得开。不需要新机制。

**如果你不同意：** 把初中那一侧关掉即可（两种学段都只做「脱节才标」）。
代价是初中学生少一条他们的 rubric 认的升格路径。

## 3. R10「讨论反例与适用条件」 vs G31「500 字任务不强制多条理由」

**定：按目标篇幅决定这一步是必经还是只提一句** —— 这不是我的发明，是产品
负责人自己的 **G24**「结合任务确定理由数量与证据要求」。

- 短任务（中考量级的短文 / 短文章）：不单独走这一步。要求落在**那一条理由
  自己身上** —— 说清它在什么情况下成立，一句话，不是一段。
- 长任务：照 R10 原样，「讨论反例与适用条件」是必经的一步。

**为什么这样切：** R10 要防的是「把一个看法说成放之四海而皆准」；G31 要防的是
「短任务被塞进撑不住的结构」。把「适用条件」挂到那条理由上，两件事同时成立，
而且不多出一个段落。

**如果你不同意：** 把门槛调低（让更多任务走完整的那一步），或者干脆让它无条件
必经。代价分别是短文变啰嗦、或者回到 G31 点名的那种过度要求。

**注意** 这一条只说「走不走这一步」。和它同形的另一个毛病 ——
放学生走的那条线写死成「两条分论点」，不看目标篇幅 —— 2026-09-12 已经修好了
（`writing_plan_state.go` 按目标字数算，`writing_plan_invite_test.go` 用 800 字
和 3000 字两条钉着）。

## 4. 🚨 文言文字词那张闭表：九类里有五类是**补**出来的，不是老师写的

这一条不是冲突，是**出处**问题，而且它已经在线上跑着，所以单独列出来。

`reading_block.go` 的字词卡要求模型从一张闭表里选类别：

> 通假字 / 古今异义 / 一词多义 / 词类活用 / 偏义复词 / 专有名词 / 典故 / 虚词 / 实词

按 `distilled/classical-reading.md` 第 63 行的标注：

| 类别 | 出处 |
|---|---|
| 通假字、古今异义、专有名词、典故 | `[源]` —— 老师那份讲义第二层逐字列出 |
| 一词多义、词类活用、偏义复词、虚词 | `[补]` —— 按中学通行判据补的 |
| 实词 | 工程加的（2026-09-24 线上走查：「蓑」九类一条都不沾，模型于是**编**了一条理由） |

**定：留着照用。** 这五类是中学语文的通行分类，不是生造的；而且去掉它们，
一个「怒而飞」的「怒」就没有地方可落，模型只会把它塞进最近的一类或者自己编 ——
线上已经见过这种编法（「前有『舟』动词词，『蓑』修饰『笠』」，两处都是错的）。

**但这是工程的判断，不是你的教研组的判断。** 请过一眼这张表，尤其是
「偏义复词」这一类值不值得让初中生分辨。

**如果你不同意：** 闭表在 `reading_block.go` 的 `readingShapedSuffix["hanwords"]`
一处，改那一行即可；`reading_article_internal_test.go` 里钉着其中四个词，
跟着改。

## 还留在桌上的

上面四条之外，distilled 那几份文件末尾各自列了自己的缺口。最要紧的两处不是
选边问题，是**根本没做**：读后续写（高考英语写作 43%、25 分）和概要写作（16%）。
它们不是第五种文体 —— 读后续写从一篇给定的原文和两个固定段首句出发，
要把阅读面和写作面接起来。
