## 0. What exists (verified via code map) — and the decisions

**Compaction today** = fold-on-solidify ONLY. `folded_at` is set by `FoldCoachSurfaces`→`FoldChatSurface` (surface-keyed) at exactly two solidify events (`workspace_plan.go:72` proposal save, `workspace_plan_generate.go:114-121` plan gen). `coachHistoryWindow = 12` (`coach.go:34`) only *caps how many active turns are read* — it does not fold. **No size/token backstop, no rolling digest exists.** `project_summary_prose` is first-open-return-summary (different purpose, first-open-wins), not a rolling compaction target.

**The coach** = always-reply `ProposeProjectCoachReply` (`project_coach.go:58-85`), card offers deliberately OFF; its doc (`project_coach.go:16-19`) names S4 as the place they turn on, with `RunAgentStep` (`loop.go:254`, silence-default) left intact as substrate. `/coach` (`coach.go:38-147`) is JSON `{reply}`; room clients (`ReadingBlock`/`PlanBlock`/`WritingBlock`/`ReviewBlock`) parse only `{reply}`.

**The 克制 ladder** (`respond` / `hint` / `summon`) is already fully built for the reading room (`reading_router.go`, `reading_gate.go`, `readturn.go`). A cross-phase moment classifier already exists (`moment.go` `ClassifyMoment`/`EligibleMomentsScoped`, `chat_step.go:184-201` `momentCard`). Card summon + `StudioCardSheet` + envelope persistence (`card_instances.parent_node_id`, `CompleteCard`→`CommitCardMint`) all exist; `ChatSurface.tsx` already renders `StudioCardSheet` inline in a message stream.

**rabbit-hole card** — `packages/contracts/cards/rabbit-hole.json` is in `CARD_REGISTRY`; the only gap is a summon/submit path (`ExplorationView.tsx:214` `TODO(S4)`).

### Decisions (resolved by principle — student-experience first · performance > cost · educational · non-manipulative; 铁律 hold)

- **D-A · Digest = one evolving row per project, regenerated by merging overflow.** `conversation_digest(project_id PK, prose, turns_folded int, updated_at, model, tier)`. Not first-open-wins (that's summary-on-return's contract); the digest *grows* as more turns fold. (student-experience: coach never forgets; performance>cost: bounded window.)
- **D-B · Backstop folds oldest-first BY AGE, and captures content into the digest BEFORE folding.** The trigger is an active-window size estimate (rune budget, reusing the `truncateRunes` heuristic family), checked after a coach turn persists. If over budget, the oldest overflow turns are (1) composed/merged into `conversation_digest` via a **mid-tier** call, then (2) marked `folded_at`. Order matters: never fold a turn whose content isn't yet durable. (过程即数据 — nothing lost.)
- **D-C · Proposing rides the existing JSON `/coach`, gaining an optional `proposal`.** NO SSE rewrite. `ProposeProjectCoachReply` returns `(reply, *CardProposal)`; the ladder collapses cleanly: `respond` → `proposal=nil`; `hint` → `proposal=nil` but the reply text nudges toward a tool; `summon` → `proposal={cardId, reason, nudgeText}`. The room renders the proposal as a gentle, dismissable "要不要打开这张卡？" chip; **opening is the student's tap** (铁律 — triggering automatic, opening confirmed). Clicking opens the card through the *existing* summon/`StudioCardSheet` path. (student-experience: non-blocking; performance: one JSON call, no stream rewrite; 不操纵: dismissable, never modal.)
- **D-D · Proposal decision reuses the existing moment classifier, metered.** No new classifier. The coach, after composing its reply, runs the cross-phase moment→card decision (`moment.go`/`chat_step.go` primitives) over the spine projection + active surface + student text, capped per project like the existing `MaxClassifyCallsPerProject`. Metered as `Purpose="coach_propose"` under the same discipline (skip on empty/no-candidate → no spend; meter only a completed call). (YAGNI; performance; metered honesty.)
- **D-E · rabbit-hole card mints a top-level reflection node.** The exploration surface has no material node, so the completed envelope persists as a project card_instance (`parent_node_id = NULL` → top-level) and mints its node via the existing `CompleteCard`/`CommitCardMint` path, appearing in `studio.Project(...)` projections. If the mint path proves material-coupled during build, that is a plan risk to surface, not silently dropped. (过程即数据 — the reflection is durable, honest submit copy.)

## 2. Backend — compaction backstop (S4a/b)

### 2a. Oldest-first fold query (sqlc, `chat.sql`)
- `SelectOldestActiveChatMessages(project_id, keep_last)` → the non-folded turns beyond the newest `keep_last`, oldest-first (the overflow candidates). (`WHERE ct.seeded_project_id=$1 AND cm.folded_at IS NULL ORDER BY created_at ASC` minus the newest `keep_last`; implement as `... ORDER BY created_at DESC OFFSET $2` re-sorted, or a windowed query — plan pins the exact SQL.)
- `FoldChatMessagesByID(ids uuid[])` → `UPDATE chat_message SET folded_at=now() WHERE id = ANY($1)`. Age-based, surface-agnostic (unlike the surface-keyed `FoldChatSurface`, which stays for solidify).
- `GetConversationDigest` / `UpsertConversationDigest(project_id, prose, turns_folded, model, tier)` (`... ON CONFLICT (project_id) DO UPDATE`).

### 2b. Backstop routine (`internal/agent` compose + `projectcoach.go` orchestration)
- `agent.ComposeDigestMerge(ctx, prov, resolved, priorDigest string, overflowTurns []Turn) (prose string, usage, error)` — mid-tier (`ChatResolver`); system prompt = "compress these older turns into/onto the running digest; keep durable facts and the student's own reasoning; drop chit-chat; never invent." Isolated, structured-in/prose-out. On empty overflow → early return, ZERO provider calls (clone of `HasGraphContent` discipline).
- `maybeCompactBackstop(ctx, projectID)` called at the tail of `postCoach` **after** the assistant turn persists:
  1. estimate active-window size (rune sum of non-folded turns); if `<= budget` → return (no spend);
  2. `SelectOldestActiveChatMessages(projectID, keepLastN)` → overflow;
  3. `ComposeDigestMerge(priorDigest, overflow)`; meter `Purpose="coach_compact"` **only when `resolved.Provider != "" && cerr == nil`**;
  4. on success: `UpsertConversationDigest(...)` then `FoldChatMessagesByID(overflowIDs)` — **digest write precedes fold** (D-B);
  5. on compose failure: warn + return (turns stay active; retried next turn). Never fail the coach turn.
- Budget/keep constants beside `coachHistoryWindow`: `digestRuneBudget` (e.g. window over ~6000 runes triggers), `digestKeepLastN` (e.g. keep newest 8). Plan pins values.

### 2c. Projection carries the digest
`buildSpineProjection` (`projectcoach.go:65-205`) gains a leading `会话记忆` block from `GetConversationDigest` (best-effort, omitted when absent): one compact paragraph before the live slices, so the coach reads folded history as durable context (D2 generous projection).

## 3. Backend — cross-phase card proposing (S4c/d)

### 3a. Coach returns an optional proposal (`project_coach.go`, `coach.go`)
- `CardProposal{ CardID, Reason, NudgeText string }` (agent pkg).
- `ProposeProjectCoachReply(...) (reply string, proposal *CardProposal, usage, error)` — reply unchanged; proposal computed by the reused moment classifier over `{projection, activeSurface, studentText}`; nil unless the ladder reaches `summon`. Per-project cap (reuse/extend `MaxClassifyCallsPerProject`). Metered `Purpose="coach_propose"`, skip-on-no-candidate.
