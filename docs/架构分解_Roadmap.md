## 3. Slice 划分（每个 slice = 一次 spec→plan→TDD 循环）

| Slice | 含块 | 一句话目标 | 关键产出 | TDD 适配 |
|---|---|---|---|---|
| **S1** | B0+B1 | 契约骨架 + 卡渲染器（纯前端、假数据），用真实使用校验契约 | 渲染器照 HTML 渲染 SIFT×CRAAP 与让步段两卡，三态可走，提交产出标准信封 | **强**：契约/加载器/事件 reducer = 纯单测；渲染器 = RTL 行为测；视觉对齐 HTML |
| **S2** | B2 | 薄后端：LLM 网关（key 服务端 + 路由 + 计量）+ SQLite 落库 | `/chat` 与持久化跑通，标准信封落库 | **中**：路由/计量/持久化单测（mock Anthropic + in-memory sqlite）；真实 LLM 仅冒烟集成测 |
| **S3** | B3+B4 | 决策层 + `summon_card` 回灌循环 + 工作区容器 | 真实对话中 AI 调对卡 → 渲染 → 摘要回灌；专注全屏布局 | **中**：tool-use 循环/信封→回灌逻辑用 fake LLM 单测；调卡"质量"属 eval 集，非单测 |
| **S4** | B5 | 过程树：事件流 → 树 | 右侧只读树实时生长，7 类节点 | **强**：树派生是纯函数，输入事件→输出树 |
| **S5** | B6 | 评估那一刀（旗舰、异步）+「你的思维印记」 | rubric L1–L4 + 过程叙述 | **中**：prompt 组装/产物解析单测；评级质量属 anchor 样本 eval，非单测 |
| **S6** | B7 | 外壳：认证 + 主目录 + 记录页 + 设置页 | 全 app 串起来，导航 任务/记录/设置 | **中**：组件 RTL + 路由测 |

> 先把 **S1–S3** 跑通即证明 PRD §2 成功判据 1、2、4；S4 证明 #3；S5 是护城河。

## 4. UI 表面清单（取自 HTML，映射到块）

HTML 的 `sc-if` 屏/态 → 所属块：

- **认证** `authScreen` → `loginScreen` / `registerScreen` / `bindScreen`（绑定班级邀请码） → **B7**
- **左导航** 任务 / 记录 / 设置 + 头像 → **B7**
- **主目录** `showDirectory`（"你想搞懂什么？" + 任务网格 + 迷你进度） → **B7**
- **工作区** `showWorkspace`：面包屑 / `footerComposer` / `treeOpen`·`treeClosed` → **B4**（树体 → B5）
- **底部抽屉** `hasActiveCard`：`isSiftActive` / `isConcessionActive` / `craapOpen`（按需展开手风琴） / `showMethodology`（"这个工具怎么用"面板） → **B1**
- **提议气泡** 三态：提议(打开卡/暂不) / 完成(已钉到过程树) / 跳过(已记录为信号) → **B1**（由 **B3** 驱动出现）
- **评估** `showEval` / `evalLoading`「你的思维印记」 → **B6**
- **记录页** `isRecords`：`recAbility`（能力图） / `recCards`（我的工具卡·使用次数） / `recLearning`（成长回顾 + GitHub 式日历） → **B7**（数据来自 B2，叙述来自 B6）
- **设置页** `isSettings`（含 API key 入口） → **B7**（API key 服务于 B2 网关）

## 6. 不可违反（贯穿所有 slice，复述 PRD §16 + AGENTS.md）

- 客户端绝不直连模型；所有 LLM 调用走后端网关，记录档位 + token + 成本。
- 卡 spec 单一真相源在 registry；决策层目录从它派生（不手写第二份）。
- 新增卡 = 新增一份 JSON，**不改渲染器代码**（schema 驱动的验收标准）。
- 标准信封结构一旦定下不随意改（树/日历/计数/评估的共同地基）。
- 四条设计铁律：AI 克制不替学生定论 · 不操纵（卡自动触发但由学生确认打开） · 一次只问一个 · 过程即数据（跳过也记录）。
- 不做 PRD §4 / AGENTS.md「明确不做」清单里的任何一项（上瘾式游戏化等）。
