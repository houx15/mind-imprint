# Lite 学生端主题 tokens

## 来源与边界

Lite 是现有设计系统的一种主题变体，组件继续使用 `--mk-*`。已移除新版入口页与首页的 `--learning-*` 变量，不维护第二份页面配色表。

- `apps/web/src/ui/themes/lite.ts`：八个主题的完整色阶，保留原有主题 ID 与名称，新的默认顺序从松石青开始。色阶为静态值。
- `apps/web/src/ui/themes/lite.css`：学生端作用域的中性色、深色模式、背景偏好、字体、字号、间距、圆角和阴影。页面尺寸、网格、图片比例等内容布局仍属于页面 CSS，不把每个尺寸都变成主题属性。
- `apps/web/src/ui/accent.tsx`：Provider 可接收主题配色表；设置色板和 `useAccentHex` 读取同一份上下文数据。默认参数仍为原配色表，Pro 和教师端无需迁移。
- `apps/lite-web/src/LiteApp.tsx`：传入 Lite 配色表，将当前色阶通过 `--mk-theme-accent-*` 注入学生根容器。它们是传输值，不是另一份色值定义；`--mk-accent-*` 是组件消费接口。

Lite 学生根容器内的设置与未改版工作区也继承主题基础值；这不代表其布局已经完成改版。课程自己定义的内容配色、学科颜色、状态色仍保留。根容器之外的 portal 或独立全屏页面需在其后续改版时核查作用域，不宣称全站完成。

## 使用约定

改主题颜色只编辑 Lite 配色表；设置中不重新声明色值。调整字体、圆角和通用间距只编辑主题 CSS；组件使用现有 `--mk-*` token。需要新增语义时在主题来源定义，并明确用途，避免继续追加页面私有调色板。

主题 ID 与账号偏好 API 不变。未存偏好时 Lite 默认松石青；已存选择优先保留。
