## 更新基线

对照上次合并 `dca31680` 检查当前实现与最近提交。写作和教师端这段时间已有大量功能更新，本轮保留这些行为：

- 写作：结构 → 行文 → 段落 → 成稿；kind 决定节点角色，拖拽支持移出子层；整篇上下文参与段落反馈，反馈区分通过、可优化和需修改；写作版本、退回修改与已发送批改。
- 教师：表单与 AI 共用作业草稿、个性化阅读选择、学生作业预览、批改编辑与预览、家长报告编辑与 AI 对话。

## 设计处理

沿用共享 `--mk-*` tokens 和已有插画，保留可选配色与明暗主题，不引入新的品牌色系统。

- 行文：左侧论点画布、右侧结构与方法，四类结构使用关系示意图。阶段导航只表示当前位置，不把跳过的阶段显示为完成。
- 段落：完整拓扑缩略图取代裁剪的缩放画布；放大只读图支持键盘、Escape 与焦点还原。正文纸面与引导、陪练分区。
- 成稿：突出正文，审阅提示提前；段落原文可展开对照，保留原文与成稿的区别。
- 已完成写作：文档纸面、明确版本头，老师批改按总评、维度、引用与建议组织。
- 教师作业：班级汇总、类型筛选与紧凑卡片。汇总明确标注人次，同一学生多份作业不算去重人数。
- 教师批改与家长报告：原文文档头、审阅双栏、报告封面目录、编号编辑章节，保留保存、发送、导出与未保存保护。

接口、后端、prompt、持久化格式均未改。Lite 写作最新行为以 2026-09-20 写作设计与当前实现为准；没有改变 Pro 写作项目各状态及其流转。
