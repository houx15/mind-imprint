## 题库与推荐题卡续改

共享 PromptCard 统一采用纸面卡片：分类/年份抬头、题面、话题、要求、完整来源和选择按钮；首页与题库推荐区使用轻微强调底色。预览依据实际排版保留五行，ResizeObserver 检查溢出后提供全文展开，保留原始文字与题目 ID。首页备用题目卡只做局部样式统一，不影响阅读端共用组件。

题库和首页在浅/深色、1280px 电脑窗口检查；展开/收起、搜索空结果/恢复、启动正确题目 ID、页面无横向溢出及脚本错误通过。TypeScript 与生产构建通过。浏览器使用仓库题库中的六道固定题目和模拟 API，未调用生产接口。看图台：`e2e/harness/prompt-cards.html`，`?view=landing` 切到首页。
