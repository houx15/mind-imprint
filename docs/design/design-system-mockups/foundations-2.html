基础 II · 阴影 · 动效 · 滚动条 · 图标

四个基础模块一起看。阴影用暖调（偏棕，不是纯黑），呼应暖纸底。动效克制、快。滚动条纤细、默认隐身。图标统一线性风格。

阴影 / 抬升 token

对应之前定的表面四级：描边=xs、小卡/气泡=sm、项目卡=md、弹层=lg。暖调阴影（rgba 偏棕）。

描边+
shadow-xs0 1px 2px / .06 + 1px 边框
小卡/气泡
shadow-sm0 2px 8px rgba(70,45,45,.08)
项目卡
shadow-md0 6px 18px rgba(70,45,45,.11)
弹窗/抽屉
shadow-lg0 16px 40px rgba(45,28,28,.18)

动效 token

克制、快、统一缓动 cubic-bezier(.2, 0, 0, 1)（干脆的 ease-out）。悬停最快，换面板中速，换房间稍慢。全站尊重 prefers-reduced-motion。（把鼠标放到左边卡片上试试）

悬停我 · 抬起 120ms
入场 fade-up 320ms
加载中 700ms/圈
duration-fast · 120ms悬停、按下、开关、气泡菜单
duration-base · 200ms面板展开/收起、抽屉滑入、tab 切换
duration-slow · 320ms换视图/换房间、卡片入场
easing · .2,0,0,1标准缓动（进多用 ease-out，出可加速）

滚动条

纤细、圆头、默认低调，悬停才变深。宽 10px（含 3px 白边内缩），thumb 用暖灰。（滚一下右边试试）

图标系统

统一线性风格：描边 1.75px、圆头圆角、currentColor 跟随文字色。基于 Lucide（开源、风格一致），栅格 24×24，也有 20 / 16。产品内不用 emoji 当功能图标（emoji 只作内容，如问好 👋）。
