组件规范：按钮 · 表面 · 圆角 · 间距

这套规范专治你说的两个病：「太多圆角矩形、什么都长一样」和「按钮全是竖着堆的一排」。核心两条：① 表面分四级（平铺 → 描边 → 抬起 → 浮起），别什么都加阴影加大圆角；② 按钮分层级，一个视图只有一个主按钮，其余都更安静。用锁定的 accent 朱砂红 #EA5140 演示。

按钮层级

一排按钮不该长一样。主 → 次 → 幽灵 → 文字链接，视觉重量层层递减，读者一眼知道该点哪个。它们是横向并排、有主次的，不是竖着堆的一排等价按钮。

开始写作 回顾过程 稍后再说 召唤工具卡 → ⋯
主 · 实心 accent　｜　次 · 描边　｜　幽灵 · 悬停才显底　｜　文字链接　｜　图标按钮
小号主 小号次 不可用
小号用于卡片内 / 工具栏；禁用态去饱和。
铁律：一个视图只允许一个主按钮。多个「都很重要」= 没有重点。

表面 / 抬升四级

默认用平铺和描边，别动不动就阴影＋大圆角。只有「真正是一个对象」的东西（项目、卡片）才抬起；浮起只给弹层。这条一执行，界面立刻不糊。

① 平铺
只靠间距分组，无边框无阴影。
分区 / 留白
② 描边
1px 边框，小圆角，不抬起。
列表 / 工具卡 / 信息块
③ 抬起
柔和阴影，中圆角。
项目卡 / 主要对象
④ 浮起
重阴影，大圆角。
弹窗 / 气泡菜单
铁律：同一屏里抬起级（③）的卡片越少越好——它是用来「指方向」的，不是默认样式。
