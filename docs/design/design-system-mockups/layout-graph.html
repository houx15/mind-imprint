布局系统 · 图谱设计

最后两块。布局分两种外壳：平台（首页/项目，常规导航）与 studio（项目内，克制、agentic）。图谱把现有 React Flow 兔子洞对齐到新设计系统。

布局系统

断点 · mobile-first
sm 640 · 手机横 / 小平板
md 768 · 平板
lg 1024 · 笔记本
xl 1280 · 桌面（内容最大宽 1200）
外壳 A · 平台（首页 / 项目 / 图鉴）——常规导航
左侧 52px 图标导航（首页/项目/图鉴/我）＋居中内容容器（max-w 1200）。这层不打扰。
外壳 B · Studio（项目内）——克制、agentic：AI 常驻 + 可变工作面
房间脊（可折成图标）＋ AI 常驻区（~320px）＋ 工作面（flex）。全屏时脊折叠、导航收起 → 只剩 AI 与工作。
容器与断点行为
· 正文/写作面阅读宽度约 68ch，再宽不利阅读。
· 页面栅格 12 列、栏距 24、页边随断点收放（桌面 32 / 平板 24 / 手机 16）。
· 手机上 studio 堆叠：工作面占满，AI 收成底部可拉起的对话条（一个按钮唤起），保持「一直都在」。

图谱设计 · React Flow 兔子洞

画布暖纸底 + 细点阵。问题节点用马卡龙序数色（每个根一个主题色），accent 红只留给「选中 / 主操作」，所以选中一眼跳出。连线带标签：确认=实线墨色、提议=虚线灰 + 小字「印记提议」（铁律②）。
