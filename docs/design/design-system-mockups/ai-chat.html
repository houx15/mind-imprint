空态 & 插画风格

插画风格：几何线条 + 马卡龙柔色块，描边和图标同源（1.75–2px 圆头），配色只取调色板，暖、克制、不用 3D / 不用库存小人。空态 = 插画 + 标题 + 一句话 + 一个主动作。
