工具卡（思维工具卡）· 陈列

工具卡是描边/小卡级，每张取一支马卡龙辅助色，横向陈列成「卡架」。它是被 AI 召唤、由学生确认打开的——所以静态陈列时低调。

弹层家族 · 弹窗 / 抽屉 / 气泡菜单 / toast

弹层都是浮起级（重阴影＋大圆角）＋半透明遮罩。按打扰程度选：气泡菜单最轻 → toast → 抽屉 → 居中弹窗（最重，只给真正需要打断的确认）。

语义色 · 独立于 accent

成功/警告/危险必须是固定的语义色，不能借用 accent——因为学生可能把 accent 设成红色，那「删除」就没法用红了。这三支全站固定。
