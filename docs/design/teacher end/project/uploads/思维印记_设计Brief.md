# 思维印记 · 设计 Brief（喂给 Claude Design）

> 用法：先用「第 1 节」让它定设计系统；定稿后，再逐页用「第 3 节」让它出页面。配参考图效果最好。

---

## 0. 一句话给设计工具的定位

为一个 K12（IB 方向）的 **AI 思考工具**设计 Web 界面。它不是聊天 App，不是作业编辑器——它是学生带着真实任务来、和 AI 协作时被引导做结构化思考的地方。核心特色：对话过程中会弹出「交互式思维工具卡」，全过程长成一棵「过程树」。

---

## 1. 设计系统（第一轮只做这个）

**风格方向：** 参考 Toddle 这类教育平台的亲和与清晰（圆角卡片、柔和阴影、充足留白、层级分明），但**调低活泼、加一份冷静专注的智识感**。整体气质：专业、安静、可信、不喧哗。

**为什么不要太活泼：** 这个产品教学生「不被操纵、保持克制」，界面本身就不能靠花哨和游戏化刺激留人。少弹窗、少动效、少强提示。

**色彩：**
- 主色：一个沉稳的靛蓝 / 墨蓝（思考感、专注感），不要高饱和亮紫。
- 背景：大面积干净浅色（近白 / 极浅灰）。
- 强调色：克制使用，仅用于「该你思考了」这类关键时刻（如工具卡激活）。
- 语义色：完成 / 跳过 / 存疑 用低饱和的绿 / 灰 / 琥珀。

**字体：** 友好但端正的无衬线（中英文都要好看）；清晰的字阶（标题 / 正文 / 辅助三档够用）。

**形状与间距：** 中等圆角（12–16px）；柔和阴影；慷慨留白；卡片化布局。

**基础组件（这一轮要画全状态）：** 按钮（主/次/文字）、卡片、输入框、文本域、单选/多选、评分刻度（1–5 格）、标签 chip、可折叠面板（accordion）、底部抽屉（bottom sheet）。

---

## 2. 信息架构

顶层三个 tab：**任务 / 记录 / 工具卡**。
- 故意**不**做常驻左侧会话列表（区别于 ChatGPT；强调"任务"而非"聊天"，强调专注）。

---

## 3. 逐页规格（一次让它做一页）

### 3.1 任务（主目录 / 首页）
- 所有任务的网格，每张任务卡：标题、状态、上次活动时间、一个迷你进度指示。
- 顶部醒目入口「+ 新任务」，文案是一句邀请：**"你想搞懂什么？"**
- 点已有任务 = 续做；点新任务 = 进工作区。
- 真实内容示例任务："中国是否让地球变得更可持续？"

### 3.2 任务工作区（核心，最重要，专注全屏）
布局：
- **中央**：对话主轴。AI 的话**短、克制、一次只问一个**。气泡设计要安静，不要花哨。
- **底部**：工具卡触发时，从底部**升起一个大的交互窗（bottom sheet）**——这是"激活态"，视觉上接管这一刻，信号是"现在轮到你想"。
- **右侧**：**过程树**面板，边做边长，可折叠，**只读**（不是编辑器）。
- **顶部**：「← 返回所有任务」面包屑（替代左侧列表）。

**工具卡三态（务必三态都画）：**
1. **提议态**：对话里一句轻量提示 + 「打开卡」按钮（如"这儿先别急着写，我们用 SIFT 核一下这个来源？"）。学生点了才展开——绝不强制弹窗。
2. **激活态**：底部大窗，渲染整张卡。以 SIFT×CRAAP 卡为例：上半 SIFT 四步（Stop / Investigate 多来源对照表 / Find better coverage / Trace 链接核查），下半 CRAAP 五维评分（默认折叠，按需展开）。每个字段旁有「我不懂为什么」可就地展开方法论小讲解。
3. **完成态**：填完折叠成紧凑卡片，钉到右侧过程树。

**过程树的七种节点（要能视觉区分）：** 任务根 / 子问题 / 工具卡使用 / 尝试草稿 / 关键知识 / 让步修订 / 反身收口。要能一眼看出"哪里用了什么卡、哪里深、哪里跳过"。

### 3.3 记录（你的思维印记）
- **GitHub 式活动日历**（每日活跃格，越用越亮）。
- 下方一段周期性"成长回顾"（如"以前你会直接下结论，现在你会先找反方"）。

### 3.4 工具卡（我的工具卡）
- 已收集的工具卡库 + 每张的使用次数 / 最近使用。
- 按分类组织（信息素养 / 知识工具 / AOK / 伦理 / 反身性）。
- 兼作轻量"技能树"入口。

## 4. 真实内容（拿来填 mockup，别用 lorem ipsum）

场景：学生 Phoebe 要写"中国是否让地球变得更可持续？"，找到一篇"地球变绿"的公众号文章。
- SIFT 卡里：来源从"公众号" → 溯源到 NASA / Nature Sustainability（IF 32.1）。
- 让步段卡里：中心论点"中国很大程度让地球更可持续" vs 反例"中国碳排放全球第一" → 写让步段。

---

## 5. 明确不做（给设计工具的约束）

- ❌ 不是聊天 App：不要常驻左侧会话列表。
- ❌ 不是编辑器：右侧树是只读记录，不做作文撰写/排版/提交。
- ❌ 不做排行榜 / 连胜 / 徽章 / 推送等游戏化与上瘾元素。
- ❌ 不要满屏强提示、红点、弹窗轰炸。专注、安静优先。
- ✅ 桌面 Web 优先；移动端响应式以后再说。

---

## 6. 驱动设计工具的顺序建议

1. 先出**设计系统**（第 1 节），配 2–3 张 Toddle 截图当风格参照，定稿。
2. 再逐页：先**任务工作区**（最难、最值得打磨，尤其工具卡三态 + 过程树），再主目录，再记录，再工具卡。
3. 每页都要它**画出全部状态**（空态 / 激活态 / 完成态），不要只给一个"漂亮的静态图"。
