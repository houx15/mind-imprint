## 0. 一句话

给老师一个每周十分钟能看明白的班级视窗：**谁在用、用得怎么样、谁需要她、找到人之后说什么。**

---

## 1. 背景与定位

### 1.1 为什么有教师端

七大国际课程体系都严格限制教师对学生高利害作业的直接反馈（IB 一稿一评、剑桥禁止评分式反馈、OCR 只许口头反馈）。老师被锁在「不能改、却要负责、还要签真实性确认」的位置上。教师端给她唯一合法且被放大的角色：**看见学生的思考过程，在线下做出教学决定。**

### 1.2 v1 三条铁律

1. **单向只读。** 教师端的一切动作都不到达学生端。老师看数据，干预在线下（谈话、调整课堂、布置练习）发生。学生端不出现任何「老师批注」「老师留言」。
2. **说人话。** 界面上不出现内部术语（九维、L1–L4、门禁、钢人、思维跳跃、自发/提示后……）。一个第一次打开的老师不需要任何培训。完整对照见附录 A。
3. **每个判断带证据。** 教师端出现的任何评价（能力等级、关注标签、风格描述），点开都能看到支撑它的学生原话或行为记录。没有证据的判断不许上屏。

### 1.3 目标用户

国际学校 / 国际部的 GP、EPQ、TOK、AP Capstone 授课教师，或校本思辨课教师。带 1–3 个班，每班 30–40 人。能给这个产品的时间：**每周 10–30 分钟**。产品按「每周看一次 + 按需点开个别学生」的节奏设计，不追求日活。

### 1.4 老师的三个使用场景

- **周一早上 10 分钟**：打开首页，看这周班级用得怎么样、谁需要留意，决定找谁聊、下节课调什么。
- **找某学生谈话前 3 分钟**：打开该生报告，看他最近在做什么、卡在哪、用什么话开场。
- **学期末**：逐生查看报告存档部分，为签署真实性确认和撰写评语取材。

## 2. 设计原则

1. **先看见人，再看见数。** 首页的核心是「建议关注的学生」卡片，图表为它服务。
2. **用量与水平分开说。** 使用时长、对话轮次是**事实**，直接给数字；思维水平是**判断**，必须带证据、带行为描述，永不给分数。两者不混排、不合成。
3. **描述行为，不定义人。** 所有标签措辞描述最近的行为（「近两周几乎全盘接受 AI 建议」），不贴人格标签（不说「依赖型学生」）。标签基于滚动窗口计算，行为变了标签就消失。
4. **正面信号与预警同权重。** 首页既有「建议关注」也有「本周亮点」。只报忧的仪表盘老师会越来越不想打开。
5. **不可见清单和可见清单一样重要。** 老师看不到：聊天原文全文、学生写作的实时画面、预估分数、跨班排名。这些是对学校的产品承诺，写进销售材料。

## 4. P1 班级首页

默认落地页。回答：**这个班这周怎么样，我该做什么。**

### 4.1 头部

- 班级切换（多班教师下拉选择）
- 时间范围：**本周（默认）** / 本月 / 学期
- 数据更新时间（「数据截至今天 8:00」——聚合按日跑，不做实时，管理预期）

### 4.2 使用概况（四张数字卡）

| 卡片 | 示例 | 口径要点 |
|---|---|---|
| 用过平台的学生 | **24 / 30**（点击看未使用名单） | 时间范围内有任意行为即算 |
| 人均使用时长 | **1.6 小时/周** | 活跃时长：无操作超过 5 分钟不计入 |
| 人均 AI 对话 | **42 轮/周** | 学生发出的消息数，三个面合计，悬停可见分面 |
| 进行中的任务 | **18 个项目 · 12 门课** | 点击展开任务清单 |

数字卡只陈述事实，不做好坏评价（时长多不代表学得好，界面不暗示这一点）。

### 4.3 班级整体评估

顶部一句 AI 班级点评，然后分两眼看：第一眼「思考状态四分图」（对谁、用什么办法），第二眼「五个能力分布」（方法课教什么，默认收起）。

> **本周班级点评（示例文案）**：全班在「查证」上进步明显，但超过一半学生评估资料时只写「这个来源可靠」而说不出理由——下节课值得专门练「怎么说明一个来源为什么可信」。

#### 4.3.1 第一眼：班级思考状态（四分图）

用两个老师秒懂的问题给全班分组——**愿不愿意自己想**（横轴，行为意愿）× **会不会想得深**（纵轴，思考质量）：

| 组 | 界面名称 | 判定含义 | 卡片上的教学动作提示 |
|---|---|---|---|
| 肯想 · 会想 | **高主动性，高思辨性** | 主动用思维工具，思考也有质量 | 给更难的挑战，或让他带同学 |
| 肯想 · 还不会 | **高主动性，思辨待提升** | 意愿强，但查证/论证不得法 | 最值得教的一组：按最弱能力配方法练习 |
| 会想 · 不肯想 | **过度依赖 AI** | 观点有质量，却几乎全盘采纳 AI 建议 | 当面挑战：请他反驳一条 AI 建议 |
| 不肯想 · 不会想 | **学习动机不足** | 用得少，用时多为要答案 | 先谈意愿和入门，不急着教方法 |

交互与规则：

- 每组显示人数 + 学生名字（点名字进 P3，点组展开全名单）。
- **组间流动是重点信息**：头部显示与上月对比（「3 人从“思辨待提升”进入“高主动性，高思辨性”」）——这是老师教学有效性的直接回声。
- 近四周事件数不足的学生进「**数据还不够**」列，不强行分组。
- 分组基于四周滚动窗口，是状态描述不是定性；对学生、家长永不可见。
- 与附录 B 特征标签的关系：标签是 14 天**急性预警**（触发即报），分组是 28 天**慢性画像**，互不替代——「太依赖 AI」标签的学生通常落在「过度依赖 AI」组，但组不产生预警。两者名称相近，界面上标签显示为预警图标＋短语、分组显示为区块名，视觉上须可区分。

#### 4.3.2 第二眼：五个能力分布（默认收起）

五个能力，每个一条分布条（四个等级各多少人）+ 一句白话解读：

| 能力（教师端名称） | 说的是什么 | 解读示例文案 |
|---|---|---|
| **会提问** | 能把问题问清楚、给足背景 | 「9 人提问时会主动交代背景，比上月 +3」 |
| **会查证** | 判断信息可不可信，会交叉核对 | 「17 人停留在“看到答案就信”阶段」 |
| **会思辨** | 听得进反方，论证有结构 | 「6 人能主动找反方理由」 |
| **会反思** | 意识到自己怎么想、有没有被 AI 带着走 | 「本周 4 人主动修正了自己的观点」 |
| **会用 AI** | 分得清 AI 的活和自己的活，知道什么不该问 AI | 「2 人出现引用没读过的资料的行为」 |

等级名称：**起步 → 发展 → 熟练 → 优秀**。任何等级点开都显示该等级的行为定义（「熟练 = 会主动要证据，能分辨来源的可靠层级」）。

### 4.4 建议关注（首页核心区）

3–6 张学生卡。每张卡 = 头像姓名 + 特征标签 + 一句依据（尽量含学生原话）+ 一句建议动作 + 「看详细报告」按钮。

> **王一帆 · 卡住了**
> 论证检查点三次没过，两次交了空白的反方论证。他自己说：「反方就是错的，我不知道怎么写他们的理由。」
> 建议：找他聊聊，可以从这句开始——「谁会真心不同意你的结论？他手里最硬的理由是什么？」

特征标签共 6 类（触发条件见附录 B）：**卡住了 · 太依赖 AI · 引用风险 · 还没用起来 · 临近截止有风险 · 进步明显**。前五类进「建议关注」，「进步明显」进 4.5。排序：引用风险 > 临近截止 > 卡住了 > 太依赖 AI > 还没用起来。

### 4.5 本周亮点

2–3 张进步卡：学生的前后原话对比 + 发生了什么。

> **陈嘉 · 第一次主动查证**
> 之前每次都要 AI 提醒才核对来源；周三他自己停下来说：「等等，这个数据是转载的，我去找原始出处。」

没有亮点的周诚实显示「本周暂无」，不硬凑（继承成长报告「敢于空白」的原则）。

### 4.6 底部入口

「查看全部 30 名学生 →」进 P2。

## 5. P2 全部学生

一人一行的列表页。列：

| 列 | 内容 |
|---|---|
| 姓名 | 点击进 P3 |
| 本周使用 | 天数 + 时长（「4 天 · 2.1h」），未使用显示上次活跃日期 |
| 主要在做什么 | 一句话（「论文项目·搭论证阶段」「上了两节课，还没开项目」「只用聊天」） |
| 思考状态 | 四分图分组名（高主动性，高思辨性 / 高主动性，思辨待提升 / 过度依赖 AI / 学习动机不足 / 数据还不够） |
| 使用风格 | 短语：「主动用工具」「基本靠 AI 提醒」「提问多为要答案」 |
| 能力概况 | 五能力的迷你等级点 + 趋势箭头 |
| 标记 | 特征标签图标 |

支持按任意列排序、按标签/能力/使用情况筛选。**不提供「综合排名」。**

## 6. P3 学生报告

老师点进一个学生看到的页面。回答：**这个孩子最近怎么样，我该跟他说什么。**

### 6.1 概况条

最近活跃、本学期累计时长、累计对话轮次、进行中的任务。

### 6.2 他是怎么用平台的

- 三个入口的时间分布（聊天 / 上课 / 做项目）
- 使用风格三句话，全部有数据支撑：
  - 「主动使用思维工具 8 次，经提醒使用 3 次」
  - 「收到 AI 建议 21 条：采纳 12、自己改写 6、拒绝 3，拒绝时都写了理由」
  - 「聊天提问以要思路为主（约 7 成），少量直接要答案」

### 6.3 能力评估

五个能力 × 当前等级 + 近四周趋势。**每格点开三样东西**：这个等级的行为定义、支撑证据（学生原话 + 时间 + 场景）、和上一等级差在哪（「他已经会主动要证据了；下一步是自己做交叉核对」）。

每条 AI 判断旁有 👍/👎（「这个判断准吗」）。这是教师端唯一的输入动作，只回流给评估引擎做校准，学生不可见。

### 6.4 进步时刻

时间轴卡片，每张 = 时间 + 类型（白话名，见附录 A）+ 前后原话。

### 6.5 任务记录

列表：每个项目、课程、聊天主题一行（名称 · 状态 · 最近活动），点击进 P4。

### 6.6 给老师的建议

1–2 条，每条 = 观察 + 一个可直接使用的谈话开场问题。永远是问题，不是可转述给学生的答案。

### 6.7 存档（学期末启用）

AI 使用申报单、过程记录导出——为签署真实性确认和撰写评语取材。对应成长报告的存档版（workbench §14.5），教师端只做入口。

---

## 7. P4 记录详情

从 6.5 点入，按任务类型分三种：

- **项目**：阶段进度（用白话阶段名：看懂要求 → 定研究问题 → 找资料 → 评估资料 → 搭论证 → 写初稿 → 总结反思）、各检查点通过情况、关键产出（研究问题、论证图当前状态）、计划修订史（每次改计划的时间和学生写的理由——这是最像「研究日志」的教师可读材料）。
- **课程**：完成了哪些环节、最后的挑战表现如何。
- **对话**：**仅课程内和项目内的对话**提供逐轮回放，每轮标注涉及的能力 + 用了什么工具，自动标出至多三个「值得看的时刻」。**自由聊天不提供全文**，只显示主题摘要、提问模式统计，以及触发红线被系统标记的具体语句（学生在知情条款中已被告知此规则）。

## 9. 数据字典（核心字段）

| 教师端字段 | 定义与口径 | 数据来源 |
|---|---|---|
| 使用时长 | 有操作的会话时间，空闲 >5 分钟截断 | 事件流时间戳聚合 |
| 对话轮次 | 学生发出的消息数（三面合计） | `prompt_sent` + `chat_message` |
| 主动 / 经提醒用工具 | AI 前三轮未提及该工具则算主动 | `card_clicked` 及其标记 |
| 对 AI 建议的处理 | 采纳/改写/拒绝三分类及理由文本 | `suggestion_disposition` |
| 能力等级（五组） | 九个评估维度按附录 A 分组归并，取组内证据加权；等级 = 行为阶梯定级 | 评估存储（引擎标注 + 行为信号） |
| 意愿轴（愿不愿意自己想） | 主动用工具比例、拒绝/改写建议率及理由质量、检查点失败后是否重试、提问模式（要思路 vs 要答案）的加权 | 事件流多源 |
| 能力轴（会不会想得深） | 九维证据的整体定级（即五个能力的加权水平） | 评估存储 |
| 思考状态分组 | 两轴各按阈值二分成四组；28 天滚动窗口；事件数 < 阈值划入「数据还不够」；阈值用标注样本校准 | 由上两行派生 |
| 进步时刻 | 评估引擎识别的七类成长事件，白话命名 | 评估存储（T1–T7） |
| 卡住了 | 同一检查点失败 ≥3 次，或求助三步用尽仍未过 | `gate_attempt` + `rescue_triggered` |
| 太依赖 AI | 近 14 天建议采纳率 ≥90% 且零拒绝，或采纳理由高度趋同 | `suggestion_disposition` |
| 引用风险 | 近 14 天「引用未打开资料被拦」≥2 次，或打开数与引用数比例异常 | 审计日志（RL-2 拦截）+ 来源日志 |
| 还没用起来 | 14 天无任何事件 | 事件流 |
| 临近截止有风险 | 距截止 ≤14 天且（词数超限 或 未进写作阶段） | 项目元数据 + 字数 |
| 进步明显 | 本周出现进步时刻 | 评估存储 |
| 班级点评 | 引擎对本周班级证据的聚合摘要 + 下节课建议 | 评估引擎（旗舰模型，批式） |

所有聚合按日离线计算；教师端不订阅实时流。

## 10. 隐私与边界

1. **学生知情**：学生端明示老师能看到什么（能力评估、任务进度、课程与项目内对话）、看不到什么（自由聊天全文、写作过程画面）。
2. **教师不可见清单**：自由聊天原文、写作缓冲区、预估分数、跨班/跨校对比、任何形式的综合排名。
3. **标签仅教师可见**，学生端和家长报告中不出现「建议关注」及任何标签。
4. **家长报告与教师端隔离**：家长看到的是策展后的成长叙事（另立 PRD），不共享教师端的预警与标签。

## 11. v1 范围

**做**：P1–P4 全量、P5 最小集、每周摘要推送、👍/👎 校准反馈。资格覆盖跟随学生端 MVP（剑桥双包）。

**不做（明确挡需求）**：在线批改或评论学生作品、给学生发消息、在线布置/催交任务、生成课件（点评只给建议文案，一键生成教案 v1.5 再议）、家长端、导出成绩单、移动端 App（响应式网页即可）。

---

## 12. 成功指标

- 覆盖：≥70% 的老师每周至少打开一次首页
- 深度：每周人均查看 ≥3 份学生报告
- 行动有效：进入「建议关注」的学生，两周内 ≥60% 脱离该名单
- 信任：👍/👎 反馈中 👍 占比 ≥80%；被点 👎 的判断类型每月复盘
- 零穿透事故：学生端出现教师端痕迹的次数 = 0

## 13. 开放问题

1. 特征标签的触发阈值（附录 B）v1 全局固定；是否允许老师调敏感度，v2 议。
2. 「活跃时长」口径：前端心跳 vs 事件间隔推算，需工程定案。
3. 多老师共管一个班的权限模型（主教师/协作教师）。
4. 每周摘要的渠道优先级：邮件先行？国内学校场景微信是否必须 v1？
5. 学生是否被告知自己进入了「建议关注」？当前答案：否，但知情条款写明老师可见范围。
6. 五个能力组是教师端唯一口径；九个底层维度是否在任何下钻层暴露？当前答案：不暴露，仅存在于数据层。

## 14. 设计交接说明（给 UI 设计师）

### 14.1 设计顺序

1. **P1 班级首页**——先做「有数据的满状态」和「开学第一周的空状态」两版。首页是产品成败的一屏。
2. **P3 学生报告**——重点打磨「能力等级点开看证据」这一个交互，它是全产品信任感的来源。
3. P2 / P4 / P5 依次。P4 的对话回放可以最后。

### 14.2 状态矩阵（每个页面必须设计的状态）

| 状态 | 触发场景 | 设计要求 |
|---|---|---|
| 空状态·无班级 | 老师首次登录 | 引导创建班级 + 邀请码发放；两步内完成 |
| 空状态·班级新建 | 学生还没开始用 | 显示已加入人数 + 「学生开始使用后，这里会出现…」的预览示意，不是空白 |
| 数据稀薄 | 开学前两周，事件量不足 | 使用概况正常显示；评估区整体显示「还在观察中，预计 X 周后给出」——宁可不给，不给拍脑袋的判断 |
| 无预警的好周 | 「建议关注」为空 | 正面文案（「这周没有需要特别留意的学生」），亮点区照常 |
| 假期/全班沉寂 | 连续 7 天全班零使用 | 摘要暂停推送；首页显示上次活跃周期数据并标注 |
| 极端班级规模 | 5 人小班 / 40 人大班 | 四分图和列表在两个极端下都可读；40 人时名字chips截断规则 |
| 单个学生数据不足 | 新转入、低使用 | 一律入「数据还不够」，个人报告页只显示使用事实，评估区留白说明 |

### 14.3 交互定义

- **看证据**：等级、标签、点评旁的证据入口一律用**侧滑抽屉**（保留上下文），抽屉内可继续下钻到 P4；不用新开页面。
- **四分图点组**：原地展开全名单（区块下方），点名字进 P3。
- **👍/👎**：即时提交，点后变灰可撤销（当次会话内）；👎 弹出可选原因（偏高/偏低/证据不符），可跳过。
- **时间范围切换**：影响 4.2 使用概况与 4.5 亮点；4.3 评估区固定用四周窗口（切换时显示说明），避免「本周评估」这种统计上站不住的东西。
- **所有下钻路径深度 ≤3**：首页 → 学生报告 → 记录详情，到底。

### 14.4 设计验收标准

- 一位未接触过产品的国际学校教师，无讲解情况下 **2 分钟内**能说出首页四个区块各是什么、并正确指出「这周该找谁」。
- 界面出现的每个评价性文案都能在两次点击内看到依据。
- 附录 A 对照表当作 lint 规则用：左列任何词出现在视觉稿里即打回。

### 14.5 设计用假数据

评估引擎的四个锚定样本（Phoebe 全谱成长 / Marcus 被动 / Ethan 红线试探 / Eliza 高元认知）直接用作设计 fixture 的四类学生原型，再补一个「数据还不够」的转学生。视觉稿一律用这套数据，避免设计师自造不真实的示例文案。

## 附录 B · 特征标签判定（v1 固定阈值）

| 标签 | 触发条件 | 卡片上的建议动作模板 |
|---|---|---|
| 引用风险 | 14 天内引用未打开资料被拦 ≥2 次，或打开:引用比例 <1:1.5 | 「先聊检索和阅读习惯，暂不作诚信定性」 |
| 临近截止有风险 | 距截止 ≤14 天且词数超限或未进写作阶段 | 「和他对一遍剩余时间的计划」 |
| 卡住了 | 同一检查点失败 ≥3 次或求助用尽仍未过 | 附评估引擎生成的开场问题 |
| 太依赖 AI | 14 天采纳率 ≥90% 且零拒绝，或理由趋同 | 「请他当面挑一条 AI 建议反驳给你听」 |
| 还没用起来 | 14 天零使用 | 「了解是账号问题、时间问题还是意愿问题」 |
| 进步明显 | 本周出现任一进步时刻 | 展示在「本周亮点」，建议课堂表扬（不点破数据来源） |

同一学生命中多个标签时全部显示，卡片排序按上表优先级。所有标签基于 14 天滚动窗口，条件消失标签即撤。
