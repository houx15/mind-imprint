# 带读怎么带：从「先讲一遍」改成「先摆一张地图」

2026-09-10。起因是产品负责人读到 印记 开场说的第一句话：

> 我们先一起把整篇文章通读一遍。这篇文章讲的是冲突里援助组织在忙什么——以色列和
> 哈马斯在打仗，援助组织得想办法把物资送进去、把人救出来。文章里提到的组织名字不
> 少，地点也很多，第一遍读的时候不用全记住，先认个脸熟就行。读完告诉我一声。
>
> —— "I don't think this helps."

他是对的，而且这句话同时违反了它自己 prompt 里已经写着的三条规矩：

1. **它把文章讲了一遍。**「以色列和哈马斯在打仗，援助组织得想办法把物资送进去」——
   她还没读呢。第二句话就把这篇的内容说完了，后面五步全成了走过场。
2. **它替她减压。**「不用全记住，先认个脸熟就行」。`ui-copy-style` 第 7 条：
   这类话假设她怕，而这个假设本身就不尊重人。
3. **它以「读完告诉我一声」收尾。** prompt 里明写着第一轮要用一张卡片把她领进去，
   不要以这句话结束。

一条 prompt 规矩被真模型违反三次，说明的不是模型不听话，而是
[[prompt-output-must-be-verifiable-2026-09-03]] 那条：**「必须」要能在代码里验**。
但这一次更根本的问题在上一层——**我们让它在一个它必然会写砸的位置上写字**。

## 诊断

开场这一轮，模型手上有全文、有读法清单，被要求「介绍一下你排的读法，然后领她进第
一步」，还被要求「不要说出这篇文章的结论」。这是一道自相矛盾的题：要它介绍，又不
许它说内容，它只能去说「这篇大概在讲什么」——也就是内容。

所以修法不是把规矩再写重一遍，是**把这一轮的活儿拿走**：她一进来该看见的那三样东
西（这篇在问什么、它怎么组织、哪几段是承重的）由**确定性的渲染**摆出来，模型那一
轮只剩一件事——递第一张卡片。

## 调研

调研了七个开源的英文阅读 skill（`docs/reference/reading-skills/`，gitignore）。
它们分两类：五个是**一次性生成器**（吐一张 HTML 或一份 markdown，之后没有对话），
两个是**真的陪读 agent**——`kasurashan/article-active-reading-tutor` 和
`lijigang/ljg-skills` 里的 `ljg-read`。后两个和 印记 是同一种东西，值得逐条对。

七个 skill 里，有五处做法是我们没有的，而且都能落到我们已有的结构上。

### 一 · 开场是一份**约定**，不是一段介绍

`article-active-reading-tutor` 的开场，一共四十来个词：

```
好，这篇文章按 25 分钟走。
今天不通读全文，先只看 [某一段]。
今天的目标：1. … 2. … 3. …
第一步：只看标题和副标题，预测一下。正文先别读。
```

五个动作：给出范围、**明确拒绝**通读全文、划定这一次读哪儿、三条编号的目标、
一条指令加**一条禁止**。那条禁止是把「一段通知」变成「一件任务」的东西。

而且它在说这句话之前**先把文章读了一遍**（「Before saying this, open or browse the
URL to verify the title, source, date, structure, and approximate difficulty」），
读到的东西一个字都不出现在开场白里。这正是我们要的那个倒置。

### 二 · 段落按**承重**分类，而不是按难度

`ljg-read` 的 Phase 0 把每一段标成三类，标完才开始读，而且**标签决定节奏**：

| 它的叫法 | 我们的叫法 | 怎么带 |
|---|---|---|
| `[骨]` 骨架段 | **核心段** | 停下来，问一轮 |
| `[肌]` 肌肉段 | **支撑段** | 连着读过去，末尾一句「这几段在支持第 N 段」 |
| `[筋]` 筋膜段 | **过渡段** | 一句话带过 |

这是整份调研里**唯一一个真的回答了「该在哪儿停」的启发式**——按论证承重，不按生词
多少。而且它把判断标成「系统判断，可修改」，她改了就是一条真实的过程信号。

（骨/肌/筋 是比喻，`ui-copy-style` 第 10 条不让用，所以换成核心/支撑/过渡。）

### 三 · 她指的东西**多大**，决定问她什么

`article-active-reading-tutor` 写死了一张对照表：

- **一到两句** → 给它贴一个角色标签（发现 / 主张 / 证据 / 机制 / 限制 / 对比），
  或者说清两句之间是什么关系。
- **一整段** → 十五个字的大意，或者「主张 + 一个限制」。
- **一节** → 一句话，但要保住主张、证据的种类、和那句限制。
- **全文** → 三句话，而且**只在小的单位都做完之后**。

配一条明写的禁令：「不要拿一两句话去要一句概括，除非目标就是压缩。对微小的单位，
要问的是每句话在干什么、它们之间是什么关系。」

我们的阅读室本来就知道她指的是一句还是一段（点一段 / 划选一句），只是从来没用这个
信息决定问什么。

### 四 · 两条**互不相干**的梯子

一条管**她卡住了**：

1. 方向（「先不给答案。这里要找的是转折」）
2. 位置（「看第二段 however 后面」）
3. 结构（「前一句是预期，后一句是限制」）
4. 局部线索（「关键的表达是 is associated with，它比 cause 弱」）
5. 完整答案 —— **只有她明确要，才给**

另一条管**这件任务本身带多少脚手架**：任务约束 → 句子开头 → 概念提示 → 完整填空框
→ 词库 → 范例。附一条很准的分辨：**句子开头逼她自己选内容，填空框已经替她选完了**，
所以起手给开头，不给框。

还有一条值得逐字抄的：**「不会」不等于「告诉我答案」**。
「我放弃」「直接给答案」「给范例」才是要答案；「不会」「太难了」「给点提示」要的是
提示。这个分辨我们现在完全交给模型的判断，也就是没有。

### 五 · 纠正之后必须**再要一次她的产出**

同一份 rubric 里明写着一种反模式：一条以「正确说法是 X，因为 Y」结束的纠正，
是一个 bug——它把她的下一步收走了。每一条纠正都要以一句祈使收尾，产出她的再一次尝试。

配套的是一张**排序过的反馈优先级**，一轮只修最上面那一条：

```
1 主张读错了
2 证据或限制漏了
3 把相关当成因果
4 长名词短语丢了主干
5 转折、让步没读出来
6 词汇搭配
7 语法和文体
```

**词汇排第六。** 上面五条全是论证理解。这和我们「一次只问一个问题」是同一件事的两个
说法，而且它给了「问哪一个」一个确定的答案。

### 附带：两个可以直接变成教具的东西

- **把握度阶梯**（`english-close-reading-skill`）：`we show` / `we found` /
  `suggests that` / `we suspect` / `may allow` 是一道递降的梯子。中文写作者常常一律
  用「表明」，把猜测写成结论。对读英文新闻的 IB 学生，这是**分清「来源声称什么」和
  「它证明了什么」**，是一个真技能，而且可核对（看动词就行）。做成一件段落工具。
- **问题的禁忌**（`ljg-qa/QuestionDesign.md`）：「什么是 X？」「X 重要吗？」
  「X 有几个步骤？」「我们应当如何看待 X？」「X 的优缺点是什么？」——
  这五种问题一句定义就能打发，没有承重。可以逐条写成正则，在代码里验。

## 中途的两条裁定，它们改了这一版的重心

**一 · 缺的不是「一套更好的措辞」，是她手上能摆的东西。**

> the guiding, now only texts, or questions/choices/text input, is not enough.
> we have great 透镜 interaction. and we can be richer.
> we can make our ai be able to call out an interactive part and then back

也就是说：结构是对的（印记 排步骤、领着走），坏的是**教具只有一件**——透镜，
而它一篇文章只用一两次。其余每一步落到屏幕上都是一段话、一个三选一、
或者一个输入框。所以这一版真正的重点不是把开场白改短，是**多两块能用手摆的板**。

**二 · 凡是 AI 递出去的东西，都必须闭环。**

> for all interactions triggered by AI. we need to make it close-loop.
> I mean, AI trigger, student interact, student finish, AI continue.

这条不是新规矩，是 AGENTS.md 里那条「新增任何一件会离开对话的工具，都要走完
终点信号 + 产出回灌」在阅读室的说法。两块板因此**不是一套平行的运行时**，
它们就是卡片多了两种形状，走的是同一条已经闭好的回路：
印记 在回复里给一张 → 她摆 → 摆完的结果**原样变成一条真的学生消息** →
下一轮 印记 对着它说话。

透镜曾经在这条回路上断过一次（2026-09-03 同事试用：「透镜应用完毕之后，
没有响应，没有推进到下一步」），修法是 `readingLensDone`。板从第一天起就走
卡片那条路，所以它不需要第二套接线；缺的只有一节 prompt——告诉印记
「她刚把一块板摆完」的那一轮要做什么，那一节现在写在
`reading_coach.go` 的「她刚把一块板摆完的那一轮」里。

## 这一次做什么

### 1 · 导读，由确定性渲染摆出来

排读法那一次调用（`reading_plan.go`，本来就要跑）多产出三样：

```json
{"oneLine": "这篇在问什么（不是它的结论）",
 "shape":   "问题 → 证据 → 让步 → 结论",
 "load":    {"b1": "core", "b2": "support", "b3": "bridge"}}
```

存在 `reading_source.outline`（迁移 0143，jsonb，additive）。阅读室在正文顶上摆一张
**导读卡**：一句话、结构、和「共 12 段，核心段 3 段：② ⑤ ⑨」——段号可以点，点了滚过去。
核心段在正文左边有一道竖线。

模型在开场那一轮因此**没有内容可讲**，prompt 直接告诉它导读卡已经在她面前，
不要复述，只递第一张卡片。

### 2 · 段落承重进 prompt

`b3（第3段·核心）`。带读的规矩随之改成：核心段停下来问；支撑段连着过，末尾一句
说它们在支持哪一段；过渡段一句带过。

### 3 · 六条新的带读规矩，能验的都写成代码

| 规矩 | 怎么保证 |
|---|---|
| 按她指的东西的大小决定问什么 | prompt（她指了什么，服务端本来就知道） |
| 五级提示阶梯 | prompt |
| 「不会」不等于「告诉我答案」 | prompt + 一张触发词表 |
| 纠正必须以一句祈使收尾 | prompt |
| 反馈优先级，一轮只修一条 | prompt |
| 七种被禁的问题形式 | **代码**：`rejectBannedQuestion`，命中就丢掉整张卡 |
| 承重标签只能取三个值 | **代码**：越界的那一段退回「支撑」 |
| 核心段不超过三分之一，也不能一段都没有 | **代码**：越界就整份 outline 作废 |
| 生词板上的词必须在那一段里真的出现过 | **代码**：按**词边界**核对，不是子串 |

这四条是这次真正「新的不变量」：一句 prompt 里的「必须」，如果代码里验不了，
它就只是一句期望。

### 3.5 · 读法库里补三步

它们补的是我们整套读法里**根本没有的位置**，不是把已有的步骤换个说法：

| 步骤 | 它做什么 | 为什么原来没有它不行 |
|---|---|---|
| `predict` 先预测 | 只看标题，猜这篇要解决什么问题。**正文先别读。** | 它把「读」从接收变成**验证**，而这个转换只有在读之前做才有意义 |
| `label` 标注论证 | 给几句话各自贴一个角色 | 我们原来没有任何一步能检查「读懂了没有」而不去问她「读懂了没有」 |
| `recall` 合上文章复述 | 凭记忆说：主张一句话 + 两三个记住的表达 | 便宜、假不了，而且产出一条完整的过程记录 |

🚨 `recall` 排在 `hunt` **前面**：她先凭记忆说一遍，再回文章里核对自己说得准不准。
反过来是让她把刚看过的那一句背一遍，什么都测不出来。而 hunt 必须是最后一步 ——
`reading_routines_internal_test.go` 守着这条：打字的答案可以凭印象给，
点出来的句子不能。

🚨 加一种 kind 是**一次迁移**，不是改一行 Go：`reading_task.kind` 上有 CHECK 约束
（0103 立的）。Go 编译通过、十几条测试照常跑，而线上第一次排读法就会 500 ——
数据库替我们把「两处枚举没对齐」拦了下来。迁移是 0144。

### 4 · 两块板

卡片从三种变成五种。前三种是**她说**，后两种是**她摆**：

| 板 | 她做什么 | 它测的是什么 |
|---|---|---|
| `label_roles` 标注板 | 文章里的 2–4 句话，各自拖进一个角色格子 | **不问「你懂了吗」的理解检查**：贴不出来就是没读懂，而她一个字都不用写 |
| `word_bank` 生词板 | 这一段里的 3–6 个词，各自拖进「认识 / 不确定 / 不认识」 | 让「该讲哪几个词」由**她**决定，而不是模型对着一整段猜 |

三件事写死在代码里，不在 prompt 里：

- **角色格子是闭表，而且由服务端填**（主张/证据/限制/背景/对比）。模型只给句子。
  换一篇文章还是这五个格子 —— 那个「认得出」就是学习本身。
- **生词板上没有释义字段。** 板上不摆答案：她分完，印记 下一轮只讲后两格里的词。
  把释义一起发下来，这块板当场退化成一张单词表。
- **每个词都要逐字出现在它那一段里，按词边界核对。** `art` 是 `article` 的子串，
  但它不是那一段里出现过的词；子串核对会放它过去。

交互本身是**拖**（pointer 事件，触屏和鼠标同一套），但**点也能用**：
先点一张卡选中，再点一个格子。理由不是无障碍的教条，是一只手扶着手机的人
拖不动一张卡片。

### 5 · 把握度，做成一件段落工具

`readingBlockTools` 里加一条（英文文章可见）。加一件工具是**改数据不是改渲染器**，
这本来就是这张表存在的理由。

## 这一次不做，以及为什么

- **读后一句话的 L0–L3 分级。** `ljg-read` 的收尾问题（「读完这篇之后，你最想对作者
  说的一句话是什么？」）加四级评分是一个很好的过程评估口子，L0 记成**陪读失败而不是
  学生失败**尤其对。但它要新增一种 task kind + 报告那一侧的一节，是独立的一块，
  这次不塞进来。
- **同义替换链 / 隐喻链的高亮。** 「作者反复说、又不肯用同一个词说的那件事，就是他
  最在乎的那件事」——这是真方法，而且我们的段 id 让跨段高亮很便宜。但它需要一种新的
  跨段标注对象，不是一件段落工具能装下的。
- **逐词点译。** 两个 skill 默认全文对照翻译。这会把我们要的那点摩擦抹掉——中文永远
  在一次点击之外，多数人不会再读英文。翻译留在段落工具里（她要点才有），
  而且点了这件事本身是一条信号。
- **六关自测卷 / Anki 表 / 间隔重复。** 这些是作业产品，属于我们明说不占的那一层。
- **固定分钟数的时间盒。** 25 分钟对一个自己坐下来的成年人成立。进度按段数说
  （「第 2 段 / 共 12 段」），不假装知道她要读多久。
