## 写作室 · 正文阶段卡组（FlowEssay，AI 可召唤）

| id | name | description |
|---|---|---|
| `pee` | PEE 写作卡 | 把一段论证写成 Point（要点）→ Evidence（论据）→ Explanation（解释）的结构，让学生自己搭骨架，而不是让 AI 代写 |
| `toulmin` | 论证构建卡（图尔敏） | 把论点搭成能立住的结构：主张、理据、证据、反方与让步，一步步写成句子 |
| `argument-map` | 论证地图卡（结构 + 谬误） | 把一段论证拆成「论点—论据—假设」的结构图，并对照常见逻辑谬误，看它到底站不站得住 |

## 写作室 · 横切按需卡（任意状态可召唤）

| id | name | description |
|---|---|---|
| `ai-boundary` | AI 边界与幻觉核查卡 | AI 会「一本正经地编」。这张卡把 AI 的边界和可能的幻觉，变成学生练查证和判断的最佳时刻 |
| `knower-perspective` | 认知者视角·自欺自审卡 | 把同一把尺子先量向自己：识别五种自欺（确认/动机/立场/回声室/部落），再用五招自审——「我是不是只信我想信的？」 |
| `metacognition` | 元认知收口卡 | 任务收尾时，回看自己怎么想的：校准信心、找出隐藏前提、指出自己论证里最弱的一环 |
| `emotional-alignment` | 情感对齐卡（内在小人·情绪电量） | 在「激发兴趣」之前的第 -1 关：先让孩子感到被理解，找到他为什么「断电」，再慢慢把他带回好奇心 |
| `rabbit-hole` | 兔子洞·兴趣雷达卡 | 捕捉学生愿意「继续往下挖」的点，把模糊兴趣翻译成可探索方向，并把一次任务自然带向下一个洞 |
| `ethics-lenses` | 伦理判断三镜头卡 | 用三个镜头看同一个「应不应该」：后果（结果好坏）、义务（规则与权利）、品格（一个好人会怎么做），再加两个检验 |
| `ai-decision-tree` | 负责任使用 AI 决策树卡 | 在动手前先问「这件事要不要用 AI、用到哪一步」——把判断前置到使用之前 |
| `perspective-matrix` | 视角对照矩阵 | 把「不同视角」从一句口号变成一张能填的表：每个视角主张什么、凭什么、又看不见什么 |
| `concession` | 让步段 · 以退为进 | 在论证里先承认反方最强的事实，再转折反驳，使论证更有力、结构更完整 |

## 阅读室 · 学科透镜 deck（11 张）

| id | name | description |
|---|---|---|
| `craap` | 信源辨识卡 CRAAP / CRRAAB | 对单一来源做纵向体检：从时效、相关、权威、准确、目的与偏见几个维度，把「能不能引用」变成一组可判断的问题 |
| `sift` | 横向核查卡 SIFT | 不要盯着可疑页面本身较劲——离开这一页、另开标签，看别人怎么评价这个来源，再回来下判断 |
| `lens-logic` | 逻辑学：推理有没有跳步？ | 把一句话拆成证据、隐藏前提和结论，检查结论的力度有没有超过现有依据 |
| `lens-methods` | 科学方法论：证据可靠吗？ | 从概念定义、测量方式、样本、变量和误差出发，判断研究或模型结果能够支持多强的结论 |
| `lens-society` | 社会学：谁得到机会，谁承担代价？ | 从社会位置、制度安排、资源差异和权力关系出发，比较同一规则对不同群体的影响 |
| `lens-law` | 法学：权利与程序清楚吗？ | 区分权利、义务、责任和程序，检查一项规则由谁制定、如何执行、能否申诉 |
| `lens-economics` | 经济学：激励与成本如何变化？ | 观察规则怎样改变人的选择，并追踪显性成本、机会成本、收益分配和外部影响 |
| `lens-ethics` | 伦理学：哪些价值正在冲突？ | 识别一项主张所保护和牺牲的价值，比较公平、伤害、自主、尊严与责任之间的取舍 |
| `lens-history` | 历史学：这个判断依赖什么背景？ | 把主张放回它形成的时间与制度背景，观察哪些条件发生了变化，哪些惯性仍在延续 |
| `lens-communication` | 传播学：表达方式怎样影响判断？ | 观察标题、标签、隐喻和叙述角度怎样突出一部分事实，同时把另一部分移出视野 |
| `lens-systems` | 系统科学：后果会怎样传导？ | 把行动放入相互连接的系统，追踪直接影响、延迟后果、反馈循环和系统边界 |

## 阅读室 · 情境信源工具（contextual toolkit）

| id | name | description |
|---|---|---|
| `cda` | 话语分析卡 CDA | 用 Fairclough 三维框架，看穿一段话怎么用词、怎么站位来潜移默化地说服甚至支配你 |
| `money-trail` | 资金链溯源卡 | 追踪谁出的钱，看清利益如何扭曲内容——一个看似中立的结论，背后可能是被资助的叙事 |
| `multimodal-decode` | 多模态解构卡 | 拆解画面、配乐、剪辑、语速如何联手塑造你的情绪和立场——看穿视听语言的说服 |
| `spin-detector` | 营销与否认套路卡（漂绿 + FLICC） | 两套套路识别器：漂绿——看穿绿色营销里「说的」和「做的」对不上；FLICC——识别否认科学的五类常见手法 |
| `data-literacy` | 数据与统计素养卡 | 对每个数字问三件事——从哪来、跟什么比、想让你得出什么；并识别图表里的误导手法 |
| `fact-opinion-value` | 事实/观点/价值判断卡 | 把一段话里的陈述分成三类——能查证的事实、需论证的观点、藏着价值的判断，是一切清晰思考的地基 |
| `opcvl` | OPCVL 史料评估卡 | 用 IB 历史的 OPCVL 框架评估史料：来源、目的、内容、价值、局限——并升到双源对照与史观自觉 |
| `belief-spectrum` | 立场光谱卡（Belief Spectrum） | 把对错两派摊成一条连续光谱，定位各方与自己 |
| `search-plan` | 检索方向审视 | 在真正去查之前，逐条想清楚每个检索方向会给你哪一类证据、又系统性地漏掉什么 |
