# Projects Tour — E2E Walk Reference

> A step-by-step map of the guided tour's **projects journey** (the "五个房间" walk on the
> read-only demo project). Use it as an e2e checklist: each **ACTION** step is a real click
> that must land, each narration/modal step is a spotlight/copy check.

---

## Projects journey

[I suggest to try both english and chinese projects, namely students use chinese to chat, but may write in chinese or english.]

### 1. project-start

- create a project with a project prompt, select a cover, start the journey
- click start.
- chat with the AI about the question
    - [optional] Use 提问卡 for several rounds because the student doesn't have any idea about the project
    - during chat, gradually narrow down to a real project topic
    - [optional] send a link of a paper or a news, and say they got some idea from that news.
    - have their own plan idea, about 12 weeks' plan by themselves.
    - Have some or no idea about resources at this time.
- generate the plan
    - [optional] what would happen if students close after clicking generate plan, then come back again?

### 2. project-management
- view the plan. 
- [optional] students try to chat with AI about the plan and made some modifications through chatting.
- try to export the plan.
- [optional] ask AI what's the next step (can we go to proposal part?)

### 3. proposal-writing

- [optional-1] choose directly writing. write a Chinese one, and ask AI to translate for him.
- [optional-2] choose directly writing, write some paragraphs, note that need to search for some materials. ask AI where can we do such research.
- [optional-3] follow AI's guidance.
    - first AI should invite students to think about the structure.
        - what would happen if the students say that they know nothing. they don't have ideas.
    - then go to snippets. AI gives guidance. 
        - what would happen if students write chinese and ask AI to write, to translate
        - what would happen if students type only 111,222 (乱写)
        - what would happen if students ask AI to write an example paragraph, and then paste that paragraph.
        - what would happen if students want to search some materials here?
            - students add an exploration box. ask AI. AI suggest jump to reading room first. (see reading room)
    - then students go to main paper. Students drag a snippet to main paper.
        - ask AI to comment.
        - then students click comment, modify some content.
        - then students ask AI to comment again.
        - then students export the proposal, and tag it as finished.

### 4. warren map + reading room

- [from writing page]
    - a seeded page? or an empty page? student begins search in the search box
        - or student begins to talk with the AI what to search.
            - AI chat, and then, can students directly click here in the chatbox to search? or AI would suggest him to search some keywords in the search box?
        - or student click an item in the exploration box to search.
    - search, find some interesting papers. Add them.
    - Read one of them. probably find it not able to fetch text. go to the real link, get the text, paste it there. then go to read.
- [or directly]
    - Search, add, manually add some paper in the warren map, then read
- [reading room]
    - want to make some notes on the paper during he is reading.
    - ask some questions about the words, why the author writes in this way, etc.
    - some questions trigger the lens/cards
    - manually click the cards.
    - get a very good reading notes.
    - the reading notes correctly shows in the writing page.
- try at least read 3 papers or articles in one project.
- add something in library, and can also see them in warren map.
