# 个人主页完整交付验收

## 目标
从制作、个性化图片和组件，到学生发布的文章、阅读笔记、作品链接的首页与分页集合；前后端持久化、公开发布、合并 main、推送、部署及线上端到端验证全部完成后，才标记目标完成。

## 本轮决策
- 首页展示学生选择的前 3/6/9/12 件作品；全部作品页按类型筛选、分页加载。公开其他报告不意味着自动公开私有主页草稿。
- 个人作品链接为 HTTPS，纳入项目类别与同一套展示选择。
- 组件支持 SVG 文件、内嵌脚本/样式的 HTML（含 Canvas），最多 6 个、单个 100 KiB、合计 400 KiB。可命名、排序、设定高度与介绍后/作品后的位置。只发布启用组件。
- SVG 通过图片上下文展示；HTML 在无同源权限的 sandbox iframe 内运行，限制资源请求、嵌套页面和表单。编辑中的 HTML 需要主动运行预览。
- 阅读/写作报告页的发布也要接通作品集。发布成功后弹出个人主页分享链接，复制内容为“快来看看我的个人作品集吧：链接”。首次无公开主页的行为需验证，不得把未确认的私有资料直接带出。
- 动态图片保持已确认规则：私有草稿，发布时复制到公开 OSS/CDN；原始生图提示和介绍对话不进入公开响应。

## 必须获得的证据（完成前逐项更新）
- [ ] 自定义 SVG/Canvas：导入、编辑、运行、停止、保存重载、显隐、顺序、发布后访问；危险源与越权边界。
- [ ] 外部作品：新增、编辑、移除、HTTPS 校验、跨设备公开链接。
- [ ] 首页部分展示、全部作品分页/筛选，空列表/最后一页/重新发布游标/撤回报告后过滤。
- [ ] 阅读与写作报告页直接公开，已有和未有公开主页；分享弹窗及剪贴板准确内容。
- [ ] 生图、上传、私有预览、公开 CDN、公开页面无私有对话/提示词。
- [ ] 前端类型与构建、逻辑边界、后端集成测试、真实浏览器宽窄屏。
- [ ] 保留 main 现有本地提交，合并最终分支、测试合并结果、push origin。
- [ ] 正式配置、备份、迁移、部署 SHA 与运行版本一致、线上真实账号端到端。
