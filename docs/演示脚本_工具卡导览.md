# 演示脚本 · 工具卡导览

> 给主持人「照着念」的脚本。目标：~10 分钟里让观众看清 **不同工具卡长什么样**、**新的「方法」分步教学**、以及 **AI 在对的时刻自己召唤卡**。
>
> **重要心态：** 召唤是**克制**的（铁律 #1：AI 不替学生定论），靠一句开场白**不保证**召唤。所以本脚本分两条线：
> - **主线（必定成功）：** 用 `?demo` **卡片画廊**逐张翻——确定性、零等待、不依赖模型。
> - **加分项（真实但不保证）：** 在真实 App 里现场让 AI 召唤一张卡，用「先铺垫、再追问」的两轮技巧最大化命中。

---

## 0. 开场前 3 分钟（务必先做）

1. 启动应用：仓库根目录运行 `pnpm --filter web dev`，记下终端给出的地址（一般 `http://localhost:5173`）。
2. 开**两个**浏览器标签：
   - **画廊（主线）：** `http://localhost:5173/?demo` —— 直接进卡片画廊，**无需登录、无需模型、零延迟**。
   - **真实 App（加分项）：** `http://localhost:5173/` —— 登录（预置 mock 学生），并在弹出的「先连接你的模型」里填好 Key、点**测试连接**变绿。**观众进来前先连好**，免得现场等。
3. 在画廊标签里随便点一张卡走一遍（选卡 → 打开 → 提交），确认顺手。

> 画廊里**没有 LLM**，所以翻卡永远即时、永远成功——这是你演示「卡长什么样」的可靠舞台。真实 App 留给最后那一下「AI 真的会自己召唤」的惊喜。

## 2. 主线：卡片画廊导览（`?demo` 标签）

**画廊操作固定动作：** 顶部点一张卡的名字 → 出现「提议」气泡 → 点**打开** → 弹出卡面（填写区 + 「方法」面板）→ 念看点、随手填一个字段 → 点**提交** → 变成「已完成」卡，右下角的 **envelope JSON 实时更新**（这就是「过程即数据」）。

> 每翻一张卡，可以指着下方那块实时 JSON 说：「学生的每一个动作——打开方法、改字段、提交——都被结构化记录成**标准信封**，过程树和评估就长在它上面。」

### 卡 1 — SIFT×CRAAP（信息素养）·先讲「方法」面板
1. 顶部选 **SIFT×CRAAP 信息核查** → **打开**。
2. **先点任意一步标题下的「方法」**：展开后有四栏——**为什么 / 怎么做 / 什么时候用 / 例子**，关键词**加粗**。一句话讲解：「这不是一行干巴巴的提示，而是把方法本身教给学生；而且**每一步**都有自己的方法，展开这个动作也会被记录。」
3. 卡里已用 Phoebe 真实内容预填（来源溯到 NASA / Nature Sustainability）。指出它**没替学生下结论**，而是把「核查」交还给学生（铁律 #1）。

### 卡 2 — 立场光谱卡（溯源与多视角）·★视觉高潮
1. 选 **立场光谱卡 Belief Spectrum** → **打开**。
2. 看点：**一条共享的光谱轴**，各方观点和「我」都在**同一条线**上，可拖动/点击/键盘移动，彼此相对位置一目了然——这是 radio 表格做不到的。
3. 一句话讲解：「这张卡走的是**逃生舱自定义渲染器**：它可以长成任意交互，但**产出仍是标准信封**——所以过程树和评估对它和普通卡一视同仁。**自定义外观，标准产出。**」（现场拖一下滑块。）

### 卡 3 — 数据与统计素养卡（知识工具）
- 选卡 → 打开。看点：对每个数字问三件事，并用**多选**让学生勾出图表里的**误导手法**（截断坐标轴、樱桃挑选…）。「同一个渲染器，这次出现的是**多选**原语——卡的形态完全由 JSON 决定。」

### 卡 4 — 让步段 · 以退为进（知识工具）
- 选卡 → 打开。已预填 Phoebe 的反例（中国碳排放全球第一）。看点：引导学生**先承认反方最强的事实**，再**转折反驳**。「撞到反例时，AI 不帮他绕开，而是教他正面接住。」

### 卡 5 — 情感对齐卡（探究启动）·★出人意料
- 选卡 → 打开。看点：先来一个**「情绪电量」评分**，再用开放题先让学生**感到被理解**。「这张卡证明平台**不只是学术工具**——它先照顾『想不想学』，而且绝不用上瘾机制留人（铁律 #2 不操纵）。」

### 卡 6 — 伦理判断三镜头卡（AI 伦理）
- 选卡 → 打开。看点：用三个镜头看同一个「应不应该」——**后果 / 义务 / 品格**，每个镜头配追问。「一次只点亮一个镜头、一次只问一个，保护思考节奏（铁律 #3）。」

### 卡 7 — 学习报告 · AI 使用声明卡（成长与沉淀）·★收尾
- 选卡 → 打开。看点：最丰富的一张（开放题 + 多选 + 评分），整理出**第二份产出**：我如何用 AI、AI 帮在哪、**哪些是我自己的判断**。「这才是交给学校 / 家长 / 作品集的关键物——不是作业本身，而是**思考的过程**（铁律 #4 过程即数据）。」

## 3. 加分项：在真实 App 里让 AI 自己召唤一张卡（真实标签）

> 诚实预期：AI **克制**，**冷冰冰一句话**多半只换来陪练反问，不召唤。真正可靠的触发方式是**两轮**：先抛出处境，再**追问你卡住的那个点**。下面给的就是实测能召唤的两轮台词（实测约一半命中、且召唤**正确**的卡）。命中了就打开演示；没命中也没关系——顺着它的反问再补一句即可。

**演示 SIFT×CRAAP（推荐，最稳）：**
1. 新建任务，第 1 句：「我想在论文里引用一篇公众号文章「中国让地球变绿」当证据。」
2. 等 AI 回应（约 3–13 秒，会显示「思考中…」）。第 2 句追问：「我不知道这个来源到底可不可信、也不知道怎么判断，你能帮我看看吗？」
3. 多半这时它会 `summon_card("sift_craap")`，弹出提议气泡 → 点打开 → 现场填一两步 → 提交 → 右侧**过程树实时长出一节**。

**其它实测能两轮召唤的卡**（任选其一备用）：
- 立场光谱：① 「关于中国到底算不算可持续，专家分成两派吵得很凶。」② 「我现在很混乱，每一方都有道理又互相矛盾，怎么理清各方立场？」
- 伦理三镜头：① 「我在讨论中国为了发展牺牲了一些环境。」② 「我想分析这在道德上到底应不应该，但不知道从哪些角度想，能给我个框架吗？」

**单句就容易召唤的**（信号很强时）：
- 情感对齐：「这个课题太难了，我有点不想做了，感觉没什么意思。」
- 学习报告：「我差不多写完了，要交作业了——帮我整理一份学习报告和 AI 使用声明。」

> 一句话讲解：「注意它**不是每次都召唤**——这是刻意的。它先当教练陪你想，只有当你的处境**真的命中**某张卡时才递工具。这正是产品的克制。」

## 4. 收尾（30 秒，把价值钉死）

1. （真实 App 里）指右侧**过程树**：「学生每用一张卡，这棵树就长一节——全程被记录。」
2. 点左侧**记录**：按卡片统计的使用情况 / 日历。
3.（可选）**生成思维印记**：跑一遍过程评估，给出 rubric 评级 + 过程叙述。⏱️ 这一步慢（旗舰模型、不降级），适合留到最后。
4. 收口金句：「学生带**自己的真实任务**进来，在和 AI 协作中被引导做**结构化思考**，全程被记录、被评估——这就是思维印记。」

## 5. 临场应对

| 情况 | 怎么办 |
|------|--------|
| 想可靠展示某张卡 | 用 **`?demo` 画廊**，别赌实时召唤。 |
| 真实 App 里 AI 没召唤、只反问 | 顺着它的问题再补一句，把「我卡在 X，不知道怎么办」说清楚（两轮技巧）。 |
| 想换卡重来（画廊） | 顶部直接点另一张卡名即可，互不干扰。 |
| 想换话题重来（真实 App） | 点**返回所有任务**，新建任务。 |
| 转圈久（真实 App，>15s） | 正常的推理延迟，别重复点发送；借机讲解上一张卡。 |

## 6. 技术亮点（被问到时用）

- **Schema 驱动 + 逃生舱**：33 张卡共用**同一个渲染器**；少数卡（如光谱卡）可注册一个**自定义 JSX 渲染器**覆盖它——但**必须仍产出标准信封**，所以过程树/评估不受影响。新增普通卡 = 加一份 JSON。
- **每步「方法」分步教学**：每个步骤带 `{why, how, when, example}`（Markdown），就地可展开；展开本身也是被记录的信号。
- **决策层靠语义、不靠关键词**：AI 看每张卡的「何时用 + 能帮他」来判断要不要召唤，用一个 `summon_card(card_id, reason, nudge_text)` 调用接通整套卡运行时。
- **自带 Key（BYO-key）**：模型调用直接从浏览器发出，API Key 只存在你自己的浏览器里，不上传服务器。
