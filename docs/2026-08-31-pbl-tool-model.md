# PBL 工具模型：什么时候用对话，什么时候开面板

> 2026-08-31 · 配合 `/eco` 原型。这份文档记的是**判断依据**，不是实现细节；
> 实现见 `apps/lite-web/src/eco/`，逐版的变更记在
> `docs/2026-08-30-ecosystem-prototype-spec.md`。

---

## 1. 问题

项目里的每一步，之前都长成同一个样子：右侧滑出一个面板，里面三到五个输入框，
填完提交。这有两个毛病。

**第一，它违反了我们自己的铁律③（一次只问一个）。** 侧栏里五个 textarea 就是
把五个问题同时问出来——那正是这条铁律要防的事。我们在对话里守着它，在工具里
破了它。

**第二，它无聊。** 一个十三岁的人连续填七步表单，会把这件事理解成作业。而项目
之所以值得做，恰恰在于它不是作业。

## 2. 判断依据

> **对话是默认。面板必须自己挣来。**

一个工具用对话还是用面板，看**做完之后剩下什么**：

| | 对话 | 面板 |
|---|---|---|
| 剩下什么 | 几段她说过的话 | 一个她能指着争论的**东西** |
| 输入形态 | 散文 | 表格 / 并排的选项 / 要拼装的图 |
| 例子 | 关键词定义、问题界定、沟通提纲、原型测试、发布前自查 | 受众画像、案例调研、方案对比、内容盘点、问卷调研 |

判断题只有一道：**做完之后，它会变成她之后反复回去看的一个对象吗？**

- 「你希望读者看完是什么感受」——回答完就过去了。**对话。**
- 「一个 45 岁、晚上十点在手机上、只看三十秒的陈老师」——这张卡会一直挂在项目上，
  之后每一版都拿他判断。**面板。**

受众画像是这条线的样板：它的六栏本来都能在对话里问完，但那样做出来的是六段
分散在聊天记录里的答案，而不是一个她可以指着问「陈老师真的会读这一段吗」的人。

## 3. 什么会触发右侧面板

只有四类：

1. **前端工具**（结构化的卡：人物卡、对比卡、清单、问卷）
2. **文档**（草稿、报告、说明）
3. **网页**（做出来的东西本身）
4. **设计稿**（图、版式、幻灯）

其余一切在对话里发生。面板出现 = 有东西要动手做或者要看，**不是**因为流程走到了
某一格。

## 4. 工具是开放的，不是固定清单

现在有七类十九件（`ToolKind`：计划 / 调研 / 框架 / 决策 / 质疑 / 审查 / 反思）。
这是**起始库存，不是全集**。

因为渲染是 schema 驱动的——一张卡 = 一份规格，渲染器不认识具体的卡——所以
**印记可以在项目进行中现场造一件新工具**：它输出一份规格，前端就能渲染。这不是
额外功能，这是 schema 驱动本来就该兑现的东西。

对应的产品含义：印记不该被一条固定的步骤链拴住。它看着这个项目此刻缺什么，
决定是问一句话、递一件现成工具，还是临时造一件。

> ⚠️ 现场造的工具要和内置的**看起来一样、行为一样**，并且要落进同一个「成果」里。
> 一件用完就消失的工具，等于没做过。

## 5. 待定：兴趣树的时间轴

**问题：** 时间轴对一个刚来的学生和一个来了两年的学生，应该长什么样？

**已定的一条：** 刻度是**相对她自己的起点**，不是日历月份。
第一版写的是「三月 / 五月 / 七月 / 现在」——对三月入学的人成立，对别人是假的。
一个第二天就来看树的学生，会看到一段不属于她的五个月成长史。

**现在的实现：** 起点 · 半年前 · 近两个月 · 现在，并且**只显示真的有东西的刻度**
（`stopsFor`）。只剩一个刻度时，轴变成一句话——「你的树刚开始长。每读完一篇、
写完一篇、做完一个项目，它就会多一个词」——而不是一个拖不动的滑块。

**还没想清楚的：**

- 两年以上怎么办？四个桶会不会把最近两个月压得太扁？可能需要「最近一年按月，
  更早按年」这种混合分辨率。
- 「起点」到底指注册那天，还是**第一个关键词出现的那天**？倾向后者：注册那天树
  是空的，把空的一天叫「起点」没有意义。
- 假期怎么算？三个月没来，轴上应该出现一段空白，还是直接接上？倾向**留下空白**——
  过程即数据，没长的那三个月也是事实。

**这一轮顺带修掉的：** 原来十六个关键词全部出生在最后两个刻度上，也就是说前两个
刻度回放出来是一棵空树。**一段没有生长的成长回放**。数据已经铺开成 3 / 4 / 5 / 4。

## 6. 不变的

- 印记可以动手做（代码、排版、图、草稿），**不能替她判断**。
- 每一步都要说得出「这一步她判断什么」。说不出的，让印记默默做掉，别把她按在
  那儿看着然后管这叫学习。
- 分工必须有**交汇点**（`then`）：「你来做 X」是派活，「你来做 X，然后把 Y 交回来，
  我按它继续」才是分工。
- 印记产出的东西，**没有理由就不落地**。
