# P4 Async Evaluation (Backend Backbone) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move per-task evaluation off the request thread onto a river-backed async queue, scored by the 10-dimension v2 rubric with a deterministic rule-signal anchor.

**Architecture:** `POST /tasks/{id}/evaluate` inserts a `queued` evaluation row and enqueues a river job, returning `202`. An embedded river worker (started in the same API process) computes deterministic **rule signals** from the task transcript + card envelopes, injects them as ground-truth facts into the flagship eval LLM prompt (10-dim v2 rubric, N/A as a first-class outcome), parses the result, and transitions the row `running → done|failed`. The client polls `GET /tasks/{id}/evaluation` for status.

**Tech Stack:** Go (`net/http`, pgx/v5, sqlc, goose), `github.com/riverqueue/river` + `riverpgxv5` driver, testcontainers-go for DB tests, DeepSeek flagship gateway (`deepseek-reasoner`, never downgraded).

## Global Constraints

- **Eval flagship model never downgrades.** The worker resolves the model via `Deps.EvalResolver` (`gateway.NewEvalKeyResolver`) only — never the chaperone resolver. (`internal/gateway/keyresolver.go`)
- **Secrets server-side only.** No LLM key / DSN / session secret in logs, errors, the `signals` payload, or any response. Sanitize worker failures to a generic stored `error` string; log the real cause server-side via `slog`.
- **Rule pass = HARD facts only.** No semantic judgement in Go. Soft judgement stays with the LLM. The `signals` block is "facts the LLM must respect but may interpret"; N/A-candidates are *candidates* the LLM may override, never hard overrides.
- **N/A is first-class.** `level ∈ {L1,L2,L3,L4,NA}`. Never infer L1 from silence. L1 requires a positive tell.
- **Rubric version stamped on every eval.** `rubric_version = "cognitive-model-v2"` written to every finished row, so longitudinal comparison stays safe as the rubric evolves.
- **Worker is embedded in the API process** (started in `cmd/api/main.go` alongside the HTTP server) — one binary, one deploy.
- **Envelope/contract truth stays in `packages/contracts`.** This plan does not change the envelope or card JSON. The `signals` shape is a backend-only struct (not a card envelope).
- **Out of scope (separate follow-up plans):** the milestone auto-trigger (debounce + cap), and the frontend「你的思维印记」reveal UI. This plan delivers the async backbone + on-demand `POST /evaluate` only.
- **Binding instruments:** spec `docs/superpowers/specs/2026-06-29-evaluation-model-design.md`; rubric v2 anchors `docs/2026-06-28-cognitive-model-rubric.md`.

```go
package agent

import "regexp"

type CardSignal struct {
	CardID       string `json:"card_id"`
	Status       string `json:"status"`
	OpCount      int    `json:"op_count"`
	FilledFields int    `json:"filled_fields"`
	EmptyFields  int    `json:"empty_fields"`
}

type EvalSignals struct {
	MessageCount            int          `json:"message_count"`
	StudentTurnCount        int          `json:"student_turn_count"`
	AssistantTurnCount      int          `json:"assistant_turn_count"`
	StudentCharCount        int          `json:"student_char_count"`
	SourceCountStudent      int          `json:"source_count_student"`
	SourceCountAI           int          `json:"source_count_ai"`
	MaxVerbatimOverlapChars int          `json:"max_verbatim_overlap_chars"`
	Cards                   []CardSignal `json:"cards"`
	NACandidates            []string     `json:"na_candidates"`
}

var urlRe = regexp.MustCompile(`https?://[^\s,，。;；)）】]+`)

func distinctURLs(texts []string) int {
	seen := map[string]struct{}{}
	for _, t := range texts {
		for _, u := range urlRe.FindAllString(t, -1) {
			seen[u] = struct{}{}
		}
	}
	return len(seen)
}

// ComputeSignals derives deterministic HARD facts from the transcript + card
// envelopes. No semantic judgement — that stays with the eval LLM. Verbatim
// overlap (Task 3) and N/A-candidates (Task 4) are filled by later passes.
func ComputeSignals(msgs []StoredMessage, cardInsts []CardInstance) EvalSignals {
	var s EvalSignals
	var studentTexts, aiTexts []string
	for _, m := range msgs {
		s.MessageCount++
		switch m.Role {
		case "user":
			s.StudentTurnCount++
			s.StudentCharCount += len([]rune(m.Content))
			studentTexts = append(studentTexts, m.Content)
		case "assistant":
			s.AssistantTurnCount++
			aiTexts = append(aiTexts, m.Content)
		}
	}
	s.SourceCountStudent = distinctURLs(studentTexts)
	s.SourceCountAI = distinctURLs(aiTexts)

	s.Cards = make([]CardSignal, 0, len(cardInsts))
	for _, c := range cardInsts {
		cs := CardSignal{CardID: c.CardID, Status: c.Status, OpCount: c.EventTraceLen}
		for _, v := range c.FieldValues {
			if isEmptyValue(v) {
				cs.EmptyFields++
			} else {
				cs.FilledFields++
			}
		}
		s.Cards = append(s.Cards, cs)
	}
	return s
}

func isEmptyValue(v any) bool {
	switch t := v.(type) {
	case nil:
		return true
	case string:
		return t == ""
	case []any:
		return len(t) == 0
	case map[string]any:
		return len(t) == 0
	default:
		return false
	}
}
```

And add the helper (rolling DP, capped to keep it bounded on long transcripts):

```go
// longestCommonSubstring returns the rune length of the longest contiguous
// run shared by a and b. Each text is capped at maxLCSRunes to bound cost;
// copy detection only needs to know a long verbatim run exists, not its exact
// length past the cap.
const maxLCSRunes = 4000

func longestCommonSubstring(a, b []rune) int {
	if len(a) > maxLCSRunes {
		a = a[:maxLCSRunes]
	}
	if len(b) > maxLCSRunes {
		b = b[:maxLCSRunes]
	}
	if len(a) == 0 || len(b) == 0 {
		return 0
	}
	prev := make([]int, len(b)+1)
	cur := make([]int, len(b)+1)
	best := 0
	for i := 1; i <= len(a); i++ {
		for j := 1; j <= len(b); j++ {
			if a[i-1] == b[j-1] {
				cur[j] = prev[j-1] + 1
				if cur[j] > best {
					best = cur[j]
				}
			} else {
				cur[j] = 0
			}
		}
		prev, cur = cur, prev
		for k := range cur {
			cur[k] = 0
		}
	}
	return best
}
```

- Produces: `EvalSignals.NACandidates []string` — a CONSERVATIVE list of dimension ids the LLM may mark N/A unless the dialogue shows otherwise. Per the injection contract, these are candidates, never hard overrides. Rule table (facts only):
  - `D2` (信源辨识) if no external source at all: `SourceCountStudent + SourceCountAI == 0`.
  - `D3` (横向验证) if fewer than 2 distinct sources total: `SourceCountStudent + SourceCountAI < 2`.

  - `D9` (AI 边界与伦理) if the AI made no checkable turn: `AssistantTurnCount == 0`.
  - D1, D4, D5, D6, D10 are never rule-marked N/A (left wholly to the LLM).
