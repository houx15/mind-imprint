## 1. 决定摘要（brainstorm 已确认）

1. **整体采用终稿设计。** 新设计取代旧规则即取代（用户原话："we follow the newest evaluation design，if supersedes old rule, then it supersedes"）。
2. **深度轴重映射 + 改刻度。** 6 维 D1–D6，**L1–L4**（不再 0–3）；ID 重排（终稿 D2=证据与信源、新增 D4=视角与偏见）；**废弃 /12 深度小计**。
3. **自主轴改为计分。** 6 信号 A1–A6，**0–5 级**（教师可见），级别是**行为计数带**（count-band），不是质量打分。旧"自主永不计分"规则被取代。
4. **公理保留。** 「两轴永不合成总分」仍然成立：D 与 A 永不相加。全报告**唯一的聚合数字**是**项目专属的训练折算 /100**（作品就绪度，显式不与 D/A 合成）。
5. **官方投影 = 通用就绪度槽位。** `{standard, components, alignment rows, 训练折算/100}`；AP Research 是第一个插入的标准，未来 EPQ / IB EE 等作为更多标准插入。仅研究/论文项目面产出。
6. **模型自身切分：** 通用内核（D6 · A6 · 提示词透镜 · 交互证据 · 总览 · 下一步）三面通用；项目专属超集（官方投影 · 证据地图 · 作品与过程）仅项目面。
7. **投影按受众取景：** 教师全量（含内部代码 + 官方投影）；家长柔化（D 四台阶、A 三态无数字、无官方投影/无透镜、机会供给先于判定）；学生说人话。
8. **敢于空白 + 机会供给先于判定** 是模型一等公民（NA / 暂无可计入的证据；机会未提供=平台欠账 vs 机会已给未取用=学生信号）。

## 2. 规范对象（canonical object）总览

评估**只算一次**，产出一个规范对象。每个渲染面是它的投影，绝不各自重算。

```
Assessment {
  // ── 通用内核（chat / course / project 三面都产出）──
  depthAxis        [ D1..D6 各 {code,name, level:L1-L4|NA, evidence, promptEvidence?} ]
  autonomyAxis     [ A1..A6 各 {code,name, level:0-5|NA, band, count, spread, ledToRevision,
                                 opportunity: given_taken | given_not_taken | not_supplied,
                                 evidence} ]
  promptLens       { stats:[ {label,value} ×3 ],
                     lenses:[ 6 各 {code,name, level:0-5, evidence} ],
                     note }                              // 只读互动痕迹，非第三评分轴
  interactionEvidence [ {round, student, aiSummary, signal} ]   // 交互证据
  narrative        string                               // 总览摘要
  guidance         { nextSteps:[ {title,task} ] }        // 下一步脚手架
  axiom            string   // verbatim 「两轴永不合成总分；单次会话为事件级证据，不构成人级档位判定」
  generatedAt      string

  // ── 项目专属超集（仅研究/论文项目面产出；其它面为 null）──
  officialProjection?  { standard:{id,name},
                         components:[ {name, judgement, reason} ],   // AP: Academic Paper, POD, 诚信/真实性
                         alignment:[ {item, standard, performance, impact} ],
                         readiness:{ score:0-100, note } }           // 训练折算/100，作品就绪度，不与 D/A 合成
  evidenceMap?         { nodes:[ {id,label,note} ], links:[ {from,to} ], details:{ [nodeId]:{title,body} } }
  workAndProcess?      { workSamples:[ {title,text} ], processMaterials:[ {name, status, diagnosis} ] }
}
```

**公理结构化保证：** 没有任何字段跨 D/A 相加。`officialProjection.readiness.score` 是**唯一**的百分制数字，且只在项目面存在、显式标注"作品就绪度，不与 D/A 双轴合成"。深度不再有 /12 小计。

## 3. D 轴 · 认知深度（6 维，L1–L4）

**刻度语义**（家长台阶映射，`家长报告.dc.html` `dLevels`）：L1 起步 · L2 发展 · L3 熟练 · L4 优秀 · **NA 暂无可计入的证据**（不等于 L1；不判低分）。

- **L1 起步**：主要在复述资料，还没形成自己的问题和判断。
- **L2 发展**：能提出问题、找到一些证据，但论证和方法还比较薄。
- **L3 熟练**：能把问题、方法、证据和结论连成一条线，会注意研究的局限。
- **L4 优秀**：论证扎实、证据充分，能主动说明"这份研究不能说明什么"。

逐维锚点（在旧 `dualaxis.json` 0–3 锚点 + SOLO 阶梯 + 三案例证据上作 authored；L4 为新增顶层）：

### D1 任务理解与问题表述
把宽泛话题收窄成真正能研究、能回答的问题。
- **L1** 直接抛出宽泛话题/问题，不交代背景、目标或验收标准；命题绝对化。
- **L2** 给出任务背景与目标，但对象、变量或验收标准仍模糊（如"影响"含义不清，无法区分注意/态度/风险感知/行为）。
- **L3** 主动交代背景、目标与约束，把宽泛影响问题收窄成可研究的关系（对象/情境/变量清晰）。
- **L4** 在 L3 之上把绝对化命题改成有限定判断，明确结论边界与"不可回答之处"。
- **NA** 未提出可评估的任务表述 / 证据不足。

### D2 证据与信源
会不会找资料、判断资料可不可信、说清每份资料能支持什么。
- **L1** 完全信任来源、不追出处；多为新闻/网页，学术文献仅作背景引用。
- **L2** 能找到一些资料，但文献之间不比较，gap 更多是声明而非分析推出。
- **L3** 能追到一手出处并识别来源等级，比较已有研究以推出 scholarly gap。
- **L4** 溯到一手出处、识别反方证据，分析来源立场与证据适用范围；由文献关系稳定推出 gap。
- **NA** 未涉及证据或来源 / 证据不足。

### D3 论证结构
用证据一步步推出结论，而不是"结论大于证据"。
- **L1** 把观点当事实、把结果直接当结论（结论大于证据），不区分论点与论据。
- **L2** 能拆分部分 claim–evidence–reasoning，但数据解释偏描述，结论靠常识补足。
- **L3** gap–method–evidence–结论 链条基本稳定，能把证据连到有限结论。
- **L4** 识别证据与结论间缺失的 warrant，用让步段协调主张与反主张，结论谨慎且与证据匹配。
- **NA** 未展开论证 / 证据不足。

### D4 视角与偏见（终稿新增维）
有没有考虑反方观点、承认研究的局限和偏差。
- **L1** 不处理便利样本、自陈偏差、因果推断限制，无反方或替代解释。
- **L2** 承认自陈、便利样本、不能证明因果，但不深入讨论题项效度或替代解释。
- **L3** 识别多类限制（自陈/样本/因果/测量）并讨论替代解释。
- **L4** 系统处理偏见与效度，主动邀请反方，把限制转化为对结论边界的约束。
- **NA** 未涉及视角或限制 / 证据不足。

### D5 反馈处理与修订
收到质疑后，是真的改进论证，还是只改了措辞。
- **L1** 被动接受或整段照搬 AI 输出；修订停留在语言润色。
- **L2** 采纳部分建议做局部补丁（补限制、改图表说明），但未说明理由、未重构论证。
- **L3** 能分别说明采纳与拒绝的理由，先自改再求反馈；修订影响论证而非仅措辞。
- **L4** 依据审稿式反馈重构方法或收窄结论，主体性清晰，修订改变研究判断。
- **NA** 未对反馈作出可见处置 / 证据不足。

### D6 反思与元认知
能不能回头审视自己的思路，说清自己的判断是怎么来的。
**特殊规则（继承家长报告 `howList`）：反思维度只认学生亲手写的反思；无自写反思则记 NA，绝不判低分。**
- **L1** 反思停留在"我学到了 X"，不审视自己的检索与方法选择。
- **L2** 能说出研究结论的修正过程，但对自身策略反思不足。
- **L3** 能说明原假设如何随证据改变，并反思早期倾向（如因果化）。
- **L4** 持续审视判断来源，能说清"这是我的判断"及其局限。
- **NA** 无可计入的自写反思证据。

## 4. A 轴 · 智识自主（6 信号，0–5 级 · 计数带）

**级别是行为计数带，不是质量打分。** 由四个因子决定：① 可计入事件**数量**；② **自发 vs 引导后**（自发权重高）；③ 跨**阶段广度**；④ 是否**形成后续行动/修订**。

**通用计数带（各信号统一）：**
- **0 级** 0 个可计入事件。
- **1 级** 1 个，多为提醒/引导后驱动，偶发。
- **2 级** 2–3 个，部分自发，跨少数阶段；或引导后能接续。
- **3 级** 3–4 个，多为自发，跨多个阶段。
- **4 级** ~5–6 个，自发为主，跨 ≥3 阶段，至少部分形成后续行动/修订。
- **5 级** ~7+ 个，持续自发、跨全程、稳定形成修订并能自我解释；顶格谨慎，保留非满分空间。

六信号（parent `aSignals` 白话 + 三案例证据锚定"什么算一个事件"）：

| 信号 | 说的是什么 | 一个"可计入事件"是 |
|---|---|---|
| **A1 方向自主** | 是不是自己决定研究方向 | 一次由学生发起的路线判断/收窄（改题、换变量、选/弃方法） |
| **A2 发起自主** | 会不会主动查证、补证据 | 一次未被要求的自发补查/核查/二次分析 |
| **A3 边界主权** | 用 AI 时会不会设边界 | 一条有效边界句（"不要代写/不要编来源/不要替我下结论"）或带来跟进的边界动作 |
| **A4 对抗与检验** | 会不会主动请人挑刺 | 一次对手邀请（请 AI/同伴质疑 gap/方法/样本/结论）；"形成修订"额外加权 |
| **A5 判断署名** | 愿不愿为结论负责、说清"这是我的判断" | 一次自评档位/为结论范围负责/解释方法选择 |
| **A6 求真优先** | 证据不支持时愿不愿把结论改小 | 一次因不利证据实质性收窄结论（非模板式 limitations） |

**机会供给先于判定（每个信号带一个 `opportunity` 标记）：**
- `not_supplied` — 平台**尚未提供**该锻炼机会 → 记为**平台欠账**，不算学生短板；渲染"暂无·机会未提供"，**不拉低**该学生画像。
- `given_not_taken` — 机会**已提供、学生未取用** → 才算**学生信号**（0/1 级）。
- `given_taken` — 机会已提供且取用 → 正常计带。

## 5. 提示词透镜（6 透镜，0–5 级）

**只读 AI 互动痕迹，为双轴补过程证据；不是第三根评分轴，不并入任何总分。**

三张统计卡（`promptStats`，示例口径）：主动指令率 % · 有效边界句数 · 对手邀请次数。

六透镜（各 0–5 级 + 证据）：

| 透镜 | 口径 | 低级示例 |
|---|---|---|
| **五个决定完整度** | 最近 N 条提示词平均含几项决定（任务/材料/边界/验收…） | 1 级：平均 <2 项，多为"帮我写一段 introduction" |
| **提示成熟度** | 要答案/成品 vs 要过程/判断 的占比 | 1 级：要成品约 70% |
| **边界意识** | 有效边界句数 | 0 级：0 条 |
| **对手邀请** | 反方审稿/方法攻击请求次数 | 0 级：0 次 |
| **主动指令率** | 主动变更任务/选路线的轮次占比 | 1 级：<30% |
| **验收标准自给** | 提示中给出能回到 RQ/方法/证据的验收标准 | 1 级：只有"更学术/更高分"式模糊标准 |

透镜级别与 A 轴互为佐证（透镜看提示词、A 轴看行为），但**各自独立**，都不合成。

## 6. 官方作品投影（通用就绪度槽位 · AP Research 为第一实例）

**仅研究/论文项目面产出。** 通用形状，`standard` 是参数：

```
officialProjection {
  standard:   { id:"ap-research", name:"AP Research" }
  components: [ {name, judgement, reason} ]     // 各评估组件的档位判定
  alignment:  [ {item, standard, performance, impact} ]   // 官方标准逐条对齐
  readiness:  { score:0-100, note }             // 训练折算，作品就绪度，不与 D/A 合成
}
```

**AP Research（第一实例）的 components（口径见三案例）：**
- **Academic Paper**：1–5 档（示例：低 2/5、中 3/5），reason 解释档位。
- **POD**：/24（示例：低 8/24、中 14/24），含子项（Research Design /3、Argument /6、Reflect /3、Engage /6、Oral Defense /6）。
- **训练用折算**：/100（示例：低 38.3、中 59.6），只作作品就绪度参考。
- **诚信/真实性**：低/中/高 + reason（PREP/AI 使用/口头核验建议）。

**alignment 逐条对齐**的 item（AP）：Through-course inquiry · Academic Paper 1–5 档 · 官方论文必要元素 · POD 七行 rubric · PREP/真实性；每条给 {官方要求, 本作品表现, 影响}。

> Spec A 只定**字段与口径**。值的**推导方式**（旗舰整体判断 vs 机械公式）与 AP rubric 的编码保真度留给 Spec B。未来插入 EPQ/EE 时，只增一个 `standard` 及其 components/alignment 口径，形状不变。

## 7. 其余内核/超集字段

- **交互证据（内核）** `interactionEvidence[]`：逐轮 {student 输入, aiSummary, signal 评估信号}。三面都有轮次流即可产出。
- **证据地图（项目超集）** `evidenceMap`：RQ / 官方投影 / 双轴 / AI 互动 串起的项目证据节点图；来自过程图 + 评估。
- **作品与过程（项目超集）** `workAndProcess`：作品片段 + 过程材料（PREP / AI 使用 / 答辩表现 的 status + diagnosis）。
- **下一步脚手架（内核）** `guidance.nextSteps[]`：只保留能推进官方表现与双轴弱点的动作，不做泛泛润色。
- **总览（内核）** `narrative`：一句判断 + 研究概况。

## 8. 公理与 RL-5（保留 / 废弃）

**保留（verbatim 进 config + 评估器 prompt + 报告头）：**
> 两轴永不合成总分；单次会话为事件级证据，不构成人级档位判定

- **RL-5：** 诊断性证据永不当作分数/排名；无任何跨轴聚合字段。
- **唯一聚合数字：** `officialProjection.readiness.score`（/100，项目面，作品就绪度，显式不与 D/A 合成）。
- **旗舰绝不降级 · 评估器隔离 · cost-on-reject · DEC-3** 全部保留（细节在 Spec B）。

**废弃：** 旧的 `depthAxis.subtotal` /12（"唯一数字"角色转给项目面的训练折算/100，且深度改 L1–L4 无小计）；旧"自主永不计分"（A 轴现 0–5 计带）。

## 9. 投影规则（按受众取景）

同一规范对象，三种投影，只改取景不改内容。

### 9.1 教师投影（全量）
- 全部内核 + 项目超集；显示内部代码（D4 / A5 等）与官方投影。
- D 维显示 L1–L4 徽章；A 信号显示 0–5 级；透镜显示 0–5。
- 每个判断可点开证据抽屉（学生原话 + 时间 + 场景）。
- **教师端专属的 建议关注/亮点标签、6 特征标签、👍/👎 校准是 Spec D 的事件流分析，不属于本评估对象**（数据源不同，见程序分解 Spec D）。

### 9.2 家长投影（柔化，`家长报告.dc.html` 为准）
家长投影是**内核的重度柔化子集**：只有 D 逐维 + A 信号 + 总览 + opportunity + advice + glossary；**不含官方投影、不含透镜、不含证据地图**。
- **D → 四台阶**（`levelInfo`）：`L4→优秀`（含"L4 倾向"→熟练→优秀带）、`L3→熟练`（`L2-L3→发展·熟练`）、`L2→发展`（`L1-L2→起步·发展`）、else→`起步`。配色：优秀 `#3E8A6E` / 熟练 `#3E7CA8` / 发展 `#C68A3A` / 起步 `#C4574D`。
- **A → 三态无数字**（`stateInfo`）：`5级/4级→观察到主动信号`、`3级/2级→偶有·多在引导后`、`1级/0级→暂未观察到`。**家长端永不出现 A 的任何数字或等级。**
- 「机会供给先于判定」「敢于空白」「不贴标签不排名」「不合成总分不预测考分」四原则文案（`principles`）随报告固定呈现。

### 9.3 学生投影（说人话，自省取景）
- 学生看自己的内核（+ 自己项目的超集），说人话 register。
- 现有 `<DualAxisReport>`（+ Growth/Chat/Course 变体）迁到本对象上（Spec C）。
