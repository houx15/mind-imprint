# 思维印记 · 设计系统 (Design System) 设计规格

> **状态：** 已定稿（2026-08-06，与用户逐屏确认）。这是全站视觉与交互的**单一真相源**。
> **产品铁律不变：** ① AI 克制不代答 · ② 不操纵（无老虎机机制；工具卡触发自动、打开由学生确认）· ③ 一次只问一个 · ④ 过程即数据。设计系统必须表达而非违反这四条。

**Goal（一句话）：** 锁定一套「工具感、暖而克制、AI 为主线」的设计系统——配色/字体/间距/圆角/阴影/动效/组件/插画/布局/图谱/文案语气全部定值，让后续所有界面从它派生，根治「圆角矩形太多、按钮堆一排、AI 框混乱、太多嵌套侧栏」的问题。

**本 spec 的范围（重要）：** 这是「界面重构」三个子项目里的**第 1 个——设计系统地基**。它只定义 token + 组件 + 规范，不改动具体页面。另外两个子项目各自独立 spec → plan → build，且都消费本系统：
- **子项目 2 · 平台外壳**：首页（问好 + 最近项目快照 + 课程推荐）+ 项目页（方形卡 + 封面）。
- **子项目 3 · Studio（项目内 agentic 体验）**：无侧栏、AI 常驻可翻转、对话↔房间转场。

**明确不做（本轮）：** 移动端（桌面优先，暂不设计移动布局）；深色模式（浅色优先）；重写现有页面（属子项目 2/3）。

---

## 0. 设计原则

1. **工具，不是玩具。** 参照 Notion / Linear / Figma / Arc：方正、克制、信息密度合理。圆角小、装饰少、层级清楚。
2. **暖而专注。** 暖纸底 + 暖墨字 + 一支有精神的主色，既不冷冰冰 SaaS，也不幼稚。
3. **AI 是主线，界面是它打开的面。** 尤其在 studio：去掉一切多余 chrome，只剩 AI 与工作。
4. **表面/按钮/动效都有层级。** 默认平铺，只有真正的对象才抬起；一个视图只有一个主按钮；动效有因才动。
5. **系统锁定，个性只留一个旋钮**——学生可选主色 accent，其余全站固定，所以怎么选都协调。

## 3. 间距 · 圆角 · 阴影

**间距（4 的倍数）：** `4 · 8 · 12 · 16 · 24 · 32 · 48`。全站取此尺度。

**圆角（工具感，收紧）：**

| token | 值 | 用途 |
|---|---:|---|
| radius-xs | 6 | 输入、小标签 |
| radius-sm | 8 | 按钮、工具卡、描边卡（主力） |
| radius-md | 10 | 项目卡、面板、气泡菜单 |
| radius-lg | 12 | 弹窗、抽屉、大容器 |
| radius-full | 999 | 药丸、头像 |

**阴影 / 抬升四级（暖调，rgba 偏棕）：**

| token | 值 | 对应表面 |
|---|---|---|
| — 平铺 | 无 | 靠间距分组 |
| shadow-xs | `0 1px 2px rgba(70,45,45,.06)` + `1px solid #EFE7DD` | 描边卡 / 列表 / 工具卡 / 信息块 |
| shadow-sm | `0 2px 8px rgba(70,45,45,.08)` | 小卡 / 气泡 |
| shadow-md | `0 6px 18px rgba(70,45,45,.11)` | 项目卡 / 主要对象 |
| shadow-lg | `0 16px 40px rgba(45,28,28,.18)` | 弹窗 / 抽屉 / 浮层 |

> 铁律：默认平铺/描边，只有「真正是对象」的才抬起（shadow-md），浮起（lg）只给弹层。同屏抬起级越少越好。

## 4. 动效

**四原则（呼应铁律）：**
1. **有因才动**——每个动效解释一次变化，无纯装饰。
2. **快而不闹**——短时长 + ease-out，绝不弹跳/回弹/夸张 spring（那违反不操纵）。
3. **保持方位感**——东西从它该在处来去；AI 缩到侧栏 = 你知道它「在那儿」，从不失踪。
4. **一次一个焦点**——一次只引导一处，和「一次只问一个」一致。

**token：** 缓动统一 `cubic-bezier(.2, 0, 0, 1)`；`fast 120ms`（悬停/按下/开关/气泡）· `base 200ms`（面板/抽屉/tab）· `slow 320ms`（换视图/换房间/卡片入场）。全站尊重 `prefers-reduced-motion` → 降级为瞬时。

## 5. 图标

- 基于 **Lucide**（开源、风格一致）。描边 **1.75px**、圆头圆角、`currentColor` 跟随文字色。
- 栅格 **24 / 20 / 16**（导航/空态 24；按钮/工具栏 20；内联 16）。
- **产品内不用 emoji 当功能图标**；emoji 只作内容（如问好 👋）。

## 6. 滚动条

- 默认完全隐身，**仅滚动时**淡出一条浅色 thumb（accent-200 一类），停 0.7s 后消失。
- 宽 8px，圆头，track 透明。（JS 加 `.scrolling` 类驱动显隐。）

## 7. 按钮

**层级（一排不该长一样）：** 主（实心 accent，白字）→ 次（白底 + accent 描边 + accent-700 字）→ 幽灵（透明，hover 显 accent-50 底）→ 文字链接（accent-700）→ 图标按钮（白底 + hairline）。

- **尺寸：** md（padding 10×18，radius 8–10）· sm（6×12，radius 8）。
- **状态：** default / hover(accent-600) / 按下 / 禁用（去饱和 `#F0E9E1` 底 `#B8ADA2` 字）。
- **聚焦环：** `box-shadow: 0 0 0 3px rgba(accent,.15)` + accent 描边。
- **铁律：一个视图只允许一个主按钮。**

## 8. 表单控件（工具卡原语）

卡 spec 用这些原语拼，加卡不改渲染器：`text · textarea · single_choice · multi_choice · rating · link_check`（另有 `select · toggle`）。

- 输入：边框 `#E4DACF`，radius 8，聚焦 = accent 描边 + 聚焦环。占位 `#B8ADA2`。
- 单选/多选：20px 方/圆标记，选中填 accent。多选也可用**药丸 chip**（选中 accent-50 底 + accent-700 字）。
- rating：五星，填色用**警告金 `#E0A63A`**（非 accent，保持一致），hover 预览。
- toggle：44×26 药丸，开=accent。
- link_check：URL 输入 + 校验按钮 + 通过态（成功色 ✓ + 识别信息）。
- 错误态：危险色描边 + 浅底 + 一行错误说明。

## 9. Tabs / 分段控件 / 徽章 / 进度 / Tooltip

- **Tabs：** 下划线式，选中 accent 底线（正文/大纲/参考文献）。
- **分段控件：** 药丸容器 + 白色滑块（图书馆/探索）。
- **徽章：** 状态药丸（进行中=accent 浅底、已完成=成功、草稿=中性、待处理=警告）；计数徽章 = accent 实心圆。
- **进度：** 线性条（accent 填）；**阶段 stepper**（立项→阅读→写作→回顾：done=accent实心✓，current=accent 环，todo=灰）。
- **Tooltip：** 深色 `#33302E` 气泡，悬停淡入。

## 10. 卡片

**项目卡（抬起级 shadow-md，radius 10，方形对象卡）：**
- **封面** 84px：马卡龙渐变 或 上传图片。
- **状态药丸**（左上，半透明白底）：进行中/已完成/草稿。
- **⋯ 菜单**（右上）：仅悬停浮出（重命名/归档/删除）——铁律②不打扰。
- **标题** 16/600 最多两行；**元信息** 12（阶段·细节·时间）。
- **阶段进度** 四格 bar，accent 填当前进度。
- **新建卡**：虚线 hairline tile + `＋`。

**工具卡：** 描边级 radius 8，取一支马卡龙浅底，横向陈列成卡架；静态低调（被 AI 召唤、学生确认打开）。

**紧凑行：** hairline，40px 缩略图 + 标题 + meta + 右侧状态药丸（长列表/搜索）。

**（未来卡型：课程卡、评估结果卡——复用同一批原语，本 spec 不展开。）**

## 11. 列表布局

- **网格**：项目页，方卡自适应换列（`minmax(~200px,1fr)`）。
- **横向快照**：首页，可横滑，**第一张是「新建」**。
- **紧凑行**：长列表/搜索结果。

## 12. 弹层家族

按打扰程度：气泡菜单（最轻）→ toast → 抽屉 → 居中弹窗（最重）。

- **居中弹窗**（radius 12 + 遮罩 + header/body/footer，footer 右对齐 次+主）：**只用于「不确认就会出事」的动作（删除等）**。删除按钮用危险色 `#D64541`，不借 accent。
- **右侧抽屉**（radius 12 左角）：**子任务 / 独立上下文**（如兔子洞深挖 = 进入隔离上下文，关闭回主线）。
- **气泡菜单**（radius 10，shadow-lg）：⋯ 操作，含危险项红字。
- **Toast**（深色 `#33302E`，radius 11）：轻量反馈（已保存等）。

## 13. 对话框 / AI 聊天组件

- **气泡：** 印记 = 白底（radius 4/13/13/13）；学生 = accent-50 底（radius 13/4/13/13，跟 accent 走）；系统事件 = 居中 caption。
- **召唤卡 chip：** 卡图标 + 卡名 + 一句 nudge + 「打开 / 暂不」。触发自动、**打开由学生确认**（铁律②）。
- **链接 chip：** 链接图标 + 标题 + 域名 + **未读徽章**（诚实提示，不强推）。
- **Composer 三态：** ① 空（发送禁用 `#E7DDD0`）② 输入中（accent 发送）③ 印记回复中（■ 可中断）。聚焦时 accent 环。

## 14. AI 角色 · 豆豆 (Pebble) + 四态

印记的形象 = **豆豆**：一颗歪歪的软萌小豆子/鹅卵石，两只平静的眼睛。表情克制（不瞪大眼卖萌、不夸张动作）——可爱是身份，不是留人钩子（铁律②）。整颗是一个 SVG，身体填 accent-500，**跟随学生 accent 变色**。

**几何（锁定 · viewBox `0 0 40 40`）：**
- 身体 path：`M20 6 C 30 5 36.5 11 35.5 21 C 34.5 30 27 35.5 18.5 34.5 C 9.5 33.5 4.5 27 5.5 18 C 6.5 10 12 7 20 6 Z`，`fill = accent-500`（默认 `#EA5140`）。
- 眼睛：左 `ellipse cx16 cy21 rx1.9 ry2.5`、右 `cx25 cy20.4 rx1.9 ry2.5`，`fill #2A2724`；反光白点 `r0.75` 于 (15.4,20)、(24.4,19.4)。**≤28px 时眼睛放大到 `rx2.1 ry2.7` 保证可辨、可省反光点。**
- 尺寸：聊天头像 28px；大图 48–64px。

**四态（挂在豆豆上；关键帧锁定，`eye/eyes` 用 `transform-box:fill-box; transform-origin:center`）：**

| 态 | 表现 | 关键帧 |
|---|---|---|
| 思考中 | 眼睛上移（左 cy19 / 右 cy18.6）、眨眼；外圈脉冲。“印记在想…” | `blink 3s`：`0%,90%,100%{scaleY(1)} 95%{scaleY(.12)}`；脉冲圈 `circle r17.5 stroke accent`，`pulse 1.8s`：`0%{scale(.82);opacity:.5} 100%{scale(1.32);opacity:0}` |
| 生成中 | 眼睛随光标左右移；配流式文字 + 闪烁光标 | `dart 1.4s ease-in-out`：`0%,100%{translateX(-1.3px)} 50%{translateX(1.3px)}`（作用于 `<g class="eyes">`） |
| 处理中 | 外圈转 + **具体动作名**（"正在追溯来源到 NASA…"） | 环 `circle r18.5 stroke accent 2.4 dasharray "26 92"`，`spin .9s linear`（`transform-box:view-box; transform-origin:20px 20px`） |
| 完成 | 眯眼笑 + 轻弹 + 小金星 | 眼→弧 `M13.6 21.5 Q16 18.8 18.4 21.5` / `M22.6 21 Q25 18.3 27.4 21`（stroke `#2A2724` 1.7 round）；`pop 2.4s`：`0,100{scale1} 14{1.09} 30{.99} 44{1}`；金星 `fill #E0A63A` |

统一缓动仍是 `cubic-bezier(.2,0,0,1)`；全部尊重 `prefers-reduced-motion`。

## 15. 加载（豆豆加载家族）

- **骨架屏**（渐变 shimmer）而非空白转圈，保持布局稳定：文本骨架 / 项目卡骨架 / 列表行骨架。`shim 1.3s`：`0%{background-position:-200px 0} 100%{200px 0}`，底 `linear-gradient(90deg,#F1EBE3 25%,#F8F4EE 50%,#F1EBE3 75%)`。
- **三种豆豆加载：**
  1. **骑进度条（一般 / 房间加载 / 长任务）** — 一条 accent 进度条向右填充，**豆豆站在条上方、底压条顶边**、随填充头前进并滚动（植物大战僵尸那种）。带小地面阴影。已知 % 时豆豆停在对应位置。
     - 轨 `background:#FBE0DC`（accent-100）；填充 `fill 3.6s ease-out`：`0%{width:2%;opacity:1} 88%{96%} 96%{100%} 100%{100%;opacity:0}`。
     - 骑手 `ride 3.6s ease-out`：`left 0→calc(100% - 30px)` 同步 + `rotate 0→~660deg` + 末尾 opacity→0；`bottom` 使豆豆底压在条顶。纤细页顶版同理，豆豆更小。
  2. **行内 / 小加载** — 豆豆原地滚：`spin 1s linear`（`to{rotate360}`），尺寸 20–26px。
  3. **兔子洞（探索 / 深挖）** — 地面上一个**洞**（不是帐篷）：dirt 后沿 + 深色椭圆 + 前沿（前沿盖住豆豆使其"沉进去"，z 序：rim 1 / dark 2 / 豆豆 3 / lip 4），旁边种一根胡萝卜。豆豆蹦两下一头栽进洞、被吞掉、循环。
     - `hop 2.9s ease-in-out`：两段抛物跳（落地 `scaleY(.82)` 挤压）→ 到洞口 `scale(.95)` → 沉入 `scale(.55)→.24` + `opacity 1→0` + 一路 `rotate 0→340deg`。
     - 色：dirt `#D8B78A/#CBA877/#E8CDA0`，洞 `#17130f→#423a34`，胡萝卜 `#EE7A2E`（ridge `#D9631D`）+ 叶 `#5FA35C/#6FB06A/#7FB87A`，草 `#A6C88F`。
- 按钮内 spinner；"印记正在打字" 三点跳动。
- 所有 accent 引用跟随学生 accent；尊重 `prefers-reduced-motion`。
- **权威可视样例：** `docs/design/design-system-mockups/pebble-progress-v2.html`（骑条）· `pebble-loader.html`（行内）· `pebble-rabbithole-v2.html`（兔子洞）· `pebble-states.html`（四态）。

## 17. 布局系统（桌面优先，不做移动端）

- **断点：** sm 640 / md 768 / **lg 1024 / xl 1280**（内容最大宽 1200）。目标是桌面；小屏优雅降级但非本轮设计对象。
- **外壳 A · 平台**（首页/项目/图鉴）：左侧 52px 图标导航（首页/项目/图鉴/我）+ 居中内容容器。常规、不打扰。

## 18. 图谱设计（React Flow 兔子洞）

对齐现有实现——**只换视觉 token + 两处结构微调**，不改逻辑。

- **画布：** 暖纸底 + 细点阵（18px，点色 `#E7DDD0`）；纤细控件。
- **Level 1 · 问题图：** 问题节点 = 白卡 radius 10 + **马卡龙序数色左条**（每根一色），标题 13/600 + meta。**选中 = accent 环**（accent 只留给选中/主操作，所以跳出）。**连线带标签**：确认 = 实线墨 2px；提议 = 虚线 `#C9BCAD` + 小字「印记提议·确认？」（taro 色，铁律②）。
- **Level 2 · 思维导图**（进入某问题）：中心问题（taro 浅底）+ 采纳论文节点。**论文节点显示标题**（作者·年份作次要一行）+ 来源封面色点；节点白卡 radius 8。**连接用曲线**（bezier，`#D9CFC4`），不用直线。悬停浮出 ⋯（深挖/采纳/移除）。

## 19. 文案语气 (Voice & Tone)

**原则：**
1. **像同伴，不像系统**——温暖、第二人称、鼓励。
2. **说人话，不端着**——不用矫情/自指的诗化说法（"印记陪你想"），不把内部术语丢给学生（"溯源体检" 是我们的词，不是学生的）。
3. **鼓励，但不操纵**——温和邀请（…吧／…哦）可以；绝无紧迫/FOMO/连胜等把戏（铁律②）。
4. **分区语气**——**陪练 coach 保持克制**（一次只问一个、不加语气词）；**onboarding / 空态 / 营销可活泼**。同一产品，两种语域。
5. **不用行话**——面向学生的文案不出现 "agentic" 等技术词，用平白说法。

**Before → After：**

| 位置 | 现在 | 改后 |
|---|---|---|
| 空项目 | 带一个你真实的任务进来，印记陪你想。 | 快来创建你的第一个写作项目吧！ |
| 空图书馆 | 粘一个文献链接，印记帮你溯源体检。 | 好的写作建立在阅读之上哦 · [粘贴文献链接] |
| 陪练（保持克制） | *不变* | 它可信在哪一点？先说你的判断。 |

**后续任务：** 全站扫一遍现有 student-facing 文案，按此语气重写（列为开放项）。

## 20. 实现约定

- **Token 落地：** 全部 token 作 CSS 自定义属性（沿用现有 `mk-*` 命名）+ Tailwind theme extend，位于 `apps/web`。
- **accent 主题化：** accent 色阶作 `:root` 上的 CSS 变量；学生选 accent = 换这组变量（8 预设）。中性/语义/马卡龙固定。数据侧泛化现有 `users.card_theme`。
- **插画：** `apps/web/src/assets/illustrations/`，SVG import；undraw 上线前统一染色。
- **图谱：** 复用现有 React Flow 组件，替换视觉 token + 加 Level-2「标题」字段 + 曲线边。
- **豆豆动效如何落地（重要）：** 动效是**纯 CSS `@keyframes` + 内联 SVG**，不是烘进 SVG 的。实现 = 把 mockup 里的 SVG 标记 + 关键帧**逐字复制**进 React 组件，动作与 mockup 完全一致。**做成组件、不要做成静态 .svg 文件**——因为静态 svg 会丢掉：① accent 主题化（身体色须走 `var(--accent)` 跟随学生 accent）② 四态切换（prop 驱动）③ 进度条骑手的动态宽度/位置（数据驱动）。组件建议：`<Pebble state size>` · `<PebbleProgress value?>`（骑条，无 value=不确定态）· `<PebbleInlineSpinner>` · `<RabbitHoleLoader>`。颜色一律 `var(--accent)`。
- **可视样例（实现时对照）：** 全部交互 mockup 已存 `docs/design/design-system-mockups/*.html`（可直接浏览器打开）。canonical 最终版：`typography-v3` · `foundations-2`（阴影/动效/滚动条/图标）· `components-spec`（按钮/表面/圆角/间距）· `components-forms` · `cards-detailed` · `ai-chat` · `motion-ai` · `illustration-gallery` · `layout-graph-v2` · `pebble-states` / `pebble-progress-v2` / `pebble-loader` / `pebble-rabbithole-v2`（豆豆）· `accent-selectable`（accent 模型）。其余为迭代过程稿。
- **本 spec 是纯视觉/交互系统**；把它应用到具体页面（首页/项目/studio/图谱）= 子项目 2/3 的 spec 与 plan。
