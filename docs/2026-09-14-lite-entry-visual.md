## 改动

本批范围为阅读入口、写作入口、项目入口、分级阅读库。沿用已确认的 A 版，增加统一的插画页头、浅色背景、青绿操作色及清晰的输入区。移除阅读和写作旧有的圈字、光晕装饰；未新增生成图，人物插画复用第一批本地素材。

入口页在宽屏下保持完整导航；工作区仍使用紧凑导航。修复折叠导航露出半截文字、小屏按钮换行，以及暗色下操作色的对比度问题。样式限定在 Lite 入口页，未修改共享 Pro 组件。

原有创建、上传、历史抽屉、推荐数据、阅读搜索与难度选择、项目主页前置门槛、看板与拖拽代码保留。合入 main 后新增的阅读文件类型和写作导入功能保留。没有添加作业数据、修改 API 或重构业务流程。
