01 算法设计

报告分两半：事实半部完全确定性、零模型调用；判定与文字半部按「每条判定需要的数据上下文」把旗舰调用分区——只需一个切片的判定用精简调用，依赖全过程的判定共享一次全量调用，避免把大 digest 重复喂进去。所有调用都被限制只能引用证据候选表里的真实 id，落库前由 ValidateRefs 丢掉幻觉 id。

事实半部 · 确定性（无 LLM）

计数（AI 轮次 / 材料 / CountWords / 批注数 / 修订）、里程碑（立题完成 / 提案 / 写作 / 完成）、时间线、材料清单（usedIn = 引用→章节，退化到探索线索）、工具卡使用。

判定半部 · 四路旗舰调用

A/B/C 三路互不依赖，并发执行；D 综述依赖 C 的两轴结果，随后串行。每路都以证据候选表接地。

04 结果质量

综述文字克制、诚实、不吹捧——严格贴合铁律①（AI 克制）。它对弱 persona 直说骨架空、对强 persona 也指出材料/正文未落地。以下为真实生成节选：

你搭起了一个论文该有的骨架：收窄问题、评估来源、使用论证结构、保留让步与限制。但骨架里还缺具体内容：问题没有真正收窄，来源与正文反复使用同一……— 陈默（L1，深度 1.7 / 自主 0.3）
你在思维层面表现出较强的边界意识：多次把相关与因果区分开，主动用让步段和有限结论收窄问题，也在反思中署名自己的判断。但材料记录和正文写作仍停……— 何萱（L3，深度 3.5 / 自主 4.2）

注 · 基准数据是合成的。10 个 persona 的正文由模板化段落生成，因此综述里反复出现「更像研究动作的排演/框架，还没填入具体内容」——这是生成器忠实地读出了种子数据的模板性，不是缺陷。真实学生数据上判定会更饱满。

05 发现与下一步

  • 判别力成立。深度/自主均值随 persona 强度单调上升（L1≈1.7/0.2 → L3 顶格 3.5/4.2），弱项（未溯源、模板化正文）被如实标记。
  • id 接地有效。ValidateRefs 在稀疏数据上拦下大量幻觉引用（L1 陈默 15/35），保证报告里的深链不指向空。
  • D6 反思截断已修复。反思段原被正文摘录截断 → 智能前置「学生自写反思」块，冒烟中反思型 persona 的 D6 由 1 → 3。
  • abstract 偶发解析失败（9/10）。赵敏 的综述调用未产出可解析 JSON（26s 快速失败），报告优雅降级为空综述、其余完整。下一步：给 D 加一次重试 / 提高 MaxTokens 余量。
  • rubric 是成本与时延长杆（54% 输出 token / 48% 时延）。若需再降时延，可把 C 再拆成 depth / autonomy 两路并发——以更多调用换更短墙钟。
  • 成本可忽略：$0.027/报告。异步生成（P4 river worker）下完全可接受。
